# Recovery Possibilities — реалистичная оценка

## Главный вывод (без иллюзий)
**Этот файл — движок Unity (`libunity.so`), а не код игры.** Он одинаков для любой игры на Unity 6000.3.13f1 с теми же настройками сборки. Игровая логика, механики шутера/фарма, C#-скрипты, ассеты и сцены **физически отсутствуют** в этом файле.

Проверено тестами:
- Экспорты = только движок (`UnityInitialize`, `UnitySendMessage`, `UnitySwappy_*`), нет `il2cpp_*`/`mono_*`.
- Структур регистрации IL2CPP (`g_CodeRegistration`, `Il2CppCodeGenModule`, `Il2CppClass`, `Il2CppMetadataRegistration`) — **0**.
- Магия `global-metadata.dat` (0xFAB11BAF) — **не найдена** ни в одном порядке байт.
- Сигнатур методов игровых типов — **0** (есть только имена типов/сборок/полей).

**→ Восстановление игровых механик из этого файла НЕВОЗМОЖНО.** (Прямо сообщаю, как и требовалось.)

## Применимость инструментов к ЭТОМУ файлу
| Инструмент | Применим? | Почему |
|---|---|---|
| `readelf`/`nm`/`objdump -t` | частично | секции разрушены; работает только разбор сегментов/.dynsym вручную |

| Ghidra / IDA / radare2 | да (ограниченно) | можно дизассемблировать **код движка**, но это чужой стандартный движок — смысла для восстановления игры нет |
| **Il2CppDumper** | **нет** | нужен `libil2cpp.so` + корректный `global-metadata.dat`. Здесь их нет |
| **Il2CppInspector** | **нет** | то же |
| **Cpp2IL** | **нет** | нужен `libil2cpp.so` + metadata |
| AssetStudio/AssetRipper | нет | нужны `*.assets`/`*.bundle`/`resources.assets` (ассеты) |
| dnSpy/ILSpy | нет | нужен `Assembly-CSharp.dll` (Mono-билд) |

## Про повреждения файла
Файл повреждён в метаданных ELF (section headers + указатель PT_DYNAMIC). Это НЕ мешает сути вывода и в принципе чинится **на копии** (переписать PT_DYNAMIC на реальное смещение `0xc8a05b4` и обнулить/починить section headers). Но даже идеально починенный `libunity.so` сам по себе игру не восстанавливает и запускается только в составе полного Android-приложения.

## Честный итог
Из имеющегося файла реально получить **техпаспорт и архитектурную карту проекта** (что и сделано), но **не исходный код и не механики**. Для восстановления игры нужны ДРУГИЕ файлы — см. `Documentation/missing_files.md`.
