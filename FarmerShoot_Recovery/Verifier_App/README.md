# Farmer SO Verifier v2 — APK

Лёгкое (16 КБ) приложение. **Важно:** в v1 проверка шла по фиксированным оффсетам из `test.so` и
давала «✗», потому что `test.so` смещён/побит — его оффсеты не совпадают с оригиналом, хотя Build-ID тот же.

**v2** ищет якоря **по содержимому** в `libunity.so` установленной игры и показывает их **НАСТОЯЩИЕ**
оффсеты (а не битые из test.so). Плюс умеет извлечь файлы для восстановления. Без root.

## Что делает
- Проверяет **Build-ID** (`69815f2befe135c2`).
- Ищет якоря в оригинале и выводит их реальные оффсеты: `UnityInitialize`, `RadarView`,
  `RadarMapView`, `RadarConfiguration`, `Balders.farmershoot.Game`, `AimDispersionCurve`.
- Показывает, есть ли в игре **`libil2cpp.so`** и **`global-metadata.dat`**, и их размер.
- Кнопка **«Извлечь …»** копирует `libil2cpp.so` + `global-metadata.dat` в
  `Android/data/com.recovery.sofarmerverify/files/` (забрать проводником/USB или `adb pull`).

## Как пользоваться
1. Установите APK (разрешите «из неизвестных источников») или `adb install FarmerSO-Verifier.apk`.
2. **«Авто-поиск игры (по Build-ID)»** — найдёт вашу игру среди установленных. Или введите пакет вручную.
3. **«Проверить оффсеты»** → увидите реальные оффсеты якорей.
4. **«Извлечь …»** → достанет настоящие файлы для восстановления игры.

## Результат
- **✓ Рабочий** — Build-ID совпал и якоря найдены: данные подлинны и есть в установленной игре
  (в test.so они были по другим, смещённым адресам — вот почему v1 писал «✗»).
- **✗ Не совпадает** — другой Build-ID (иная сборка) или якоря не найдены (иная игра/версия).

## Честная граница
Приложение проверяет **подлинность и совпадение** оффсетов/значений (чтение файла установленной игры).
Оно НЕ запускает чужой код и НЕ читает память чужого процесса (это невозможно без root и не нужно).
«Рабочий» = данные подлинные и идентичны установленной игре, а НЕ «игра восстановлена».

## Сборка из исходника
`src/com/recovery/sofarmerverify/MainActivity.java` + `AndroidManifest.xml`.
Сборка: `aapt2 link` → `javac` → `d8` → `zipalign` → `apksigner` (debug-ключ).
