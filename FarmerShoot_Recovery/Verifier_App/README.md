# Farmer SO Verifier — APK

Лёгкое (16 КБ) приложение, которое проверяет **оффсеты и значения**, извлечённые из вашего `test.so`,
по `libunity.so` **установленной на телефоне игры**. Без root, только чтение публичного APK игры.

## Что именно проверяет (эталоны из test.so)
| Якорь | Оффсет | Эталонное значение |
|---|---|---|
| Build-ID | 0x280 | `69815f2befe135c2` |
| Код `UnityInitialize` | 0x5ac7728 | слово `0x7100699f` (`cmp w12,#0x1a`) |
| Строка | 46402888 | `RadarView` |
| Строка | 46404335 | `RadarMapView` |

## Как пользоваться
1. Перенесите `FarmerSO-Verifier.apk` на телефон и установите (нужно разрешить «установку из неизвестных источников»).
   Либо по USB: `adb install FarmerSO-Verifier.apk`.
2. Откройте приложение.
3. Нажмите **«Авто-поиск игры (по Build-ID)»** — оно просканирует установленные Unity-игры и найдёт ту,
   чей `libunity.so` имеет Build-ID `69815f2befe135c2`. Либо введите имя пакета вручную и нажмите **«Проверить»**.

## Результат
- **✓ Рабочий** — все 4 якоря совпали: оффсеты и значения из test.so **подтверждены** в установленной игре.
- **✗ Не совпадает** — показывает, какой якорь не сошёлся:
  - Build-ID не совпал → установлена другая сборка движка (оффсеты от test.so к ней не относятся);
  - `libunity.so` (arm64) не найден → это не Unity-игра или другая ABI/пакет.

## Честная граница
Приложение проверяет **подлинность и совпадение** оффсетов/значений (чтение файла установленной игры).
Оно НЕ запускает чужой код и НЕ читает память чужого процесса (это невозможно без root и не нужно).
«Рабочий» = данные подлинные и идентичны установленной игре, а НЕ «игра восстановлена».

## Сборка из исходника
`src/com/recovery/sofarmerverify/MainActivity.java` + `AndroidManifest.xml`.
Сборка: `aapt2 link` → `javac` → `d8` → `zipalign` → `apksigner` (debug-ключ).
