# ODA

Android-приложение: выбираете страну → нажимаете кнопку → трафик идёт через Tor
с выходным узлом в этой стране. Своих серверов нет, используется сеть Tor.

Статус: **этап 1** — интерфейс без сети (подключение имитируется).

## Как получить APK на телефоне

APK собирает GitHub Actions после каждого push. Компьютер не нужен.

### 1. Дождаться сборки
1. Откройте репозиторий на github.com в браузере телефона
   (в приложении GitHub артефакты не скачиваются — нужен браузер).
2. Вкладка **Actions** (если её не видно — меню «⋯» или переключите сайт
   в режим «Версия для ПК»).
3. Сверху — последний запуск **Build APK**. Жёлтый кружок — идёт сборка
   (обычно 3–6 минут), зелёная галочка — готово, красный крестик — ошибка.
4. Запустить сборку вручную: Actions → **Build APK** → **Run workflow**.

### 2. Скачать
1. Нажмите на успешный запуск (зелёная галочка).
2. Пролистайте вниз до блока **Artifacts** и нажмите **vpn-app-debug**.
   Нужно быть залогиненным в GitHub.
3. Скачается архив `vpn-app-debug.zip`. Откройте его в приложении «Файлы»
   и извлеките `app-debug.apk`.

### 3. Установить
1. Нажмите на `app-debug.apk`.
2. Android попросит разрешить установку из неизвестных источников:
   **Настройки → Разрешить из этого источника** для приложения, через
   которое открыт файл («Файлы» или браузер). На старых версиях Android:
   Настройки → Безопасность → **Неизвестные источники**.
3. Вернитесь назад и нажмите **Установить**.
4. Google Play Защита может предупредить о незнакомом приложении —
   выберите «Всё равно установить» (APK подписан debug-ключом).

Новая версия ставится поверх старой. Если установка ругается на подпись,
удалите старую версию и поставьте заново (debug-ключ в облаке может меняться).

## Сборка
- Java, AndroidX, Material Components, без Compose, рекламы и аналитики.
- Gradle 9.8.2 (wrapper), Android Gradle Plugin 9.4.0, JDK 17.
- minSdk 24, targetSdk 36.
- Workflow: `.github/workflows/build.yml`.

## Этапы
