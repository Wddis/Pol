# TikTok-нарезки T2x2 — стиль 2 «простой»

Ветка содержит **только** этот стиль: всё нужное лежит здесь, других веток не требуется.

## Как выглядит кадр (1080×1920, 60 fps)
- чёрный фон;
- сверху вебка T2x2 — 1080×700 (y = 250);
- под ней экран стрима — 1080×608 (y = 950);
- на стыке подпись в 2 строки: 1-я **красная**, 2-я **белая**, Montserrat 900, толстая чёрная обводка, КАПСОМ;
- низ кадра свободен под интерфейс TikTok;
- `--talk` (вебка на весь экран, без экрана): одна панель 1080×1308, подпись внизу панели.

Кропы из кадра стрима 1920×1080 (раскладка T2x2), меняются переменными окружения:
| | значение | что |
|---|---|---|
| `CAM` | `440:285:1300:745` | вебка без подушки Donatov.net (сторонняя реклама = нет выплат) |
| `SCR` | `1264:711:328:0` | экран по центру: без виджета донатов, баннера FONBET, чата и вебки |
| `TALK` | `1046:1080:437:0` | вебка на весь экран |

## Звук
мат глушится (`tools/mat_mute.py`) → громкость −14 LUFS одной постоянной прибавкой (`tools/norm_audio.py`) →
под голос подкладывается `music/viyanexe_original_sound.mp3` (−17 dB, затухание в конце) → финальная нормализация, пик ≤ −3 dB.

## Порядок работы
```bash
pip install yt-dlp yt-dlp-ejs faster-whisper numpy pillow
# 1. звук стрима и расшифровка
python3 tools/vod.py <VOD> Audio_Only aud.mp4 && ffmpeg -i aud.mp4 -ar 16000 -ac 1 aud16.wav
python3 tools/stt.py aud16.wav transcript.txt
# 2. по расшифровке выбрать моменты (хук в первые 2–3 с, провокация, без 18+/ставок/рекламы)
# 3. скачать 1080p60 кусок и вырезать источник
SEGS_ONLY=1 python3 tools/vod.py <VOD> 1080p60 v.mp4 <a-12> <b+12>
python3 tools/vodcut.py <VOD> 1080p60 v.mp4.segs <a-10> <b+10> src.mp4      # печатает offset
# 4. рендер (время — в секундах файла src.mp4 = время VOD − offset)
bash render.sh src.mp4 "СТРОКА 1|СТРОКА 2" out.mp4 "s-e [s-e ...]" [--talk]
python3 tools/shorts_qc.py out out.mp4          # 1 аудиопоток, 48 кГц, −14±1 LUFS, пик ≤ −1
# 5. публикация в TikTok через BrightBean (ключ подставляет прокси сессии)
PREFIX=v2_ python3 publish.py <папка> captions.json <первый №> <последний №> <старт ISO> "15,25,35,60"
```
`examples/clips_vod2929609163.tsv` — пример списка: №, отрезки VOD, подпись «СТРОКА 1|СТРОКА 2».

## Публикация
- описание — **только** то, что требуют правила выплат: `twitch: t2x2` + теги (`captions.json`), без темы и своих слов;
- интервалы по нарастающей (`15,25,35,60,…`); последний интервал повторяется;
- лимит TikTok — **15 публикаций за 24 ч** на аккаунт (BrightBean отвечает `platform_quota`);
- правила выплат: `#t2x2` и `twitch: t2x2` в описании, без сторонней рекламы в кадре, не позже 30 дней после стрима.

## Файлы
| файл | что |
|---|---|
| `render.sh` | рендер ролика в стиле 2 |
| `overlay.py` | подпись (PNG 1080×1920, посимвольно: кириллица + знаки «?!—») |
| `publish.py` | загрузка и расписание в TikTok через BrightBean |
| `captions.json` | описание по правилам |
| `tools/` | скачивание VOD, расшифровка, глушение мата, громкость, проверка, BrightBean |
| `fonts/` | Montserrat 900 (SIL OFL, `fonts/LICENSE-montserrat`) |
| `music/` | трек «original sound — viyanexe» |
