# Telegram-бот «Двойная резка»

Бот делает весь путь этой ветки по командам из Telegram — **без ИИ-ключа**, только скриптами ветки:
слежение за стримом → расшифровка → темы-кандидаты → план монтажа → **твоя проверка моментов** → рендер
(без зума, вебка не блюрится, точечный блюр промокодов FONBET в чате, интро «Ретро-ТВ», тайм-коды) →
превью в Telegram → твоя обложка → публикация в Studio через **твои подтверждённые cookies**. Шортсы — дизайн v2 «clean».

Честно о качестве: без ИИ выбор моментов — эвристика (плотность речи, реакции, смена темы, штраф за пустые донаты
и 18+-слова). Темы стрима находит хорошо (12.11: Steam Frame 94–110 мин совпал с ручной разметкой, Верити тоже),
а «лучшие моменты» из долгой игры — хуже ручного выбора. Поэтому перед рендером бот ВСЕГДА присылает список моментов:
`/drop №` убрать, `/add 1:34:10-1:36:00` добавить, `/go` рендер. Названия видео и глав пишешь ты (`/title`, `/chapter`),
бот даёт черновик глав из первых фраз.

## Команды
| Команда | Что делает |
|---|---|
| `/vod 2926718724` или `/vod t2x2` | выбрать VOD (канал → последний) |
| `/watch` · `/stop` | следить за идущим стримом (каждые 8 мин: звук → расшифровка, видео-сегменты) |
| `/transcribe` | расшифровать весь VOD (стрим закончен) |
| `/map` · `/map 160-400` | темы стрима с оценкой и кнопками «✂️» |
| `/cut 12` · `/cut 5-9` · `/cut 94-110` · `/cut 168-384 25` | нарезка: тема / склейка тем / минуты; длинное (>45 мин) → лучшие моменты на N мин (по умолчанию 25) |
| `/drop №` · `/add a-b` · `/go` | проверка плана и запуск рендера |
| `/title …` · `/chapters` · `/chapter № …` · `/desc` · `/desc source <ссылка>` | метаданные (тайм-коды по `docs/timecodes.md`) |
| фото в чат | обложка текущей нарезки |
| `/publish` | публикация 1080p60 (ловит суточный лимит) |
| `/short 94:10-94:55 СТРОКА 1\|СТРОКА 2 [talk]` · `/stitle id …` · `/shorts` · `/pubshorts 10` | шортсы: собрать, назвать, полка, публикация с интервалом |
| `/cookies` (+ файл) · `/panel` · `/limits` · `/status` · `/jobs` · `/job id` | сервис |

Бот слушает ТОЛЬКО владельца: `TG_OWNER_ID` или однократная привязка `/pair <код из лога>`. Пароли и капчи Google
бот не вводит: если сессия слетела — пришли свежие cookies (`/cookies`).

## Запуск
1. Создай бота у @BotFather → токен.
2. Сервер: `bash tools/tgbot/install.sh` (Ubuntu). Временно и бесплатно — облачная сессия Claude Code (живёт, пока
   сессия активна; при перезапуске контейнера бота поднимают заново) или Oracle Cloud Always Free (4 ARM-ядра, 24 ГБ,
   200 ГБ диска — хватает для 1080p60). Нужно ≥ 4 ядра и ≥ 50 ГБ диска (1 час стрима 1080p60 ≈ 3,6 ГБ).
3. Токен — ТОЛЬКО в переменной окружения сервера, не в репо и не в чат: `export TG_BOT_TOKEN=…`.
4. `T2X2_WORK=~/t2x2work SHORTS_FONTS=$PWD/fonts setsid nohup python3 tools/tgbot/bot.py > bot.log 2>&1 &`
5. В Telegram: `/pair <код из bot.log>` (или задай `TG_OWNER_ID`), затем `/cookies` и пришли файл cookies, `/panel`.

Файлы: `bot.py` (бот), `studio_restrictions.js` (ограничения из Studio), скрипты ветки: `tools/auto_events.py`
(темы), `tools/auto_plan.py` (план), `tools/chat_promo_scan.py`, `tools/edit2.py`, `tools/add_intro.sh`,
`tools/timecodes.py`, `tools/shorts_template2.py`, `tools/shorts_render2.sh`, `tools/yt/*`.
