## 3. Анимация одного клипа (ключи; t0 = начало клипа, t1 = конец, mid = середина)

Порядок эффектов важен: **скорость → зум с моушен-блюром → экспозиция → тряска**.

| Эффект / свойство | Ключ 1 | Ключ 2 | Ключ 3 | Интерполяция |
|---|---|---|---|---|
| Twixtor Pro → Speed % | t0: **200** | mid: **30** | t1: **200** | F9 + Speed Graph: резкое падение в слоумо сразу после склейки, длинный «провис» 30 %, плавный разгон к следующей склейке |
| S_BlurMoCurves → Z Dist (масштаб, с моушен-блюром) | t0: **0.68** | mid: **1.0** | t1: **0.68** | F9 + кривая: «отъезд → наезд → отъезд», пик в середине |
| Exposure → Exposure | t0: **+0.4** | — | t1: **−1** | F9; вспышка в начале клипа, уход в темноту к концу |
| Opacity | t0: **0** | t0+7 кадров: **100** | t1−7 кадров: 100 → t1: **0** | линейно |
| Twitch → Amount | t0: **40** | t0+6 кадров: **0** | (так же в конце) | удар-тряска на склейке |

Twixtor: Input Frame Rate = fps исходника (смотрится в Project), Frame Interp = Blend, Motion Vectors = Best (кадр 6:10).
Перенос: эффекты и ключи копируются на все клипы; Shift — привязать первый ключ к началу клипа,
Alt-перетаскивание крайних ключей — растянуть под длину клипа без изменения формы кривых.

## 4. Переходы (из чего они получаются)

Отдельных эффектов-переходов **нет**: переход создаётся анимацией конца одного клипа и начала следующего.

| Переход | Чем сделан | Как выглядит |
|---|---|---|
| **Dip to black + zoom** (на каждой склейке музыкальной части) | конец клипа: Exposure → −1, Opacity → 0 за 7 кадров, Z Dist → 0.68, Speed → 200 %; начало следующего: Opacity 0 → 100 за 7 кадров, Exposure +0.4, Z Dist 0.68 | быстрый отъезд с моушен-блюром → затемнение 1–2 кадра → вспышка и отъезд следующего клипа; в итоговом эдите провалы в чёрное ровно на каждой склейке (каждые ~0.78 с) |
| **Speed ramp** | Twixtor 200 → 30 → 200 | клип влетает быстро, «зависает» в слоумо, вылетает быстро в склейку |
| **Impact shake** | Twitch 40 → 0 за 6 кадров | удар-тряска в первые кадры клипа, синхронно с битом |
| **Motion blur** | S_BlurMoCurves (блюр по движению зума) + RSMB на всём эдите | смазанные зумы и движения, «плавность» |
| **Defocus-переход** | Z Dist/блюр на быстром отъезде | лицо размыто → резкий следующий план (видно на 13:05–13:06) |
| **Flicker** | S_Flicker на adjustment | мерцание яркости в интро |
| **Fade to black** | Exposure −1 / Opacity | начало (0.6 с чёрного) и конец эдита |

## 5. Текст

| Параметр | Значение |
|---|---|
| Что | реплики героев из интро-сцены (оригинал, англ.), по фразе на слой (Alt+D) |
| Где | центр нижней трети вертикального кадра (на уровне груди) |
| Шрифт | жирный гротеск капсом (Montserrat-подобный), 1–2 строки |
| Появление | пресет **Fade Up** по словам: Range 0 % — герой начинает фразу, 100 % — заканчивает (слово-за-словом синхронно с речью) |
| Исчезновение | Opacity (T) в конце или **CC Burn** |
| Эффекты | **Bevel Alpha** (объём) + **Deep Glow** (Blend Mode: Screen) + **Drop Shadow**; **Twitch** скопирован с интро — текст трясётся вместе с картинкой |
| Цвет | у каждой реплики свой: белый («Two stoney on the rocks»), фиолетовый («These aren't good anymore»), пурпурный («It's a cash bar», «It'll be $25»), розово-красный («You're a fucking ugly bitch») |

## 6. Итоговый эдит (12:54–13:17 урока) — покадровый разбор

Вертикаль, ~22.8 с. Кадр: `frames/final_edit_sheet.jpg` (4 кадра/с, с 12:52). Время — от начала эдита (0.00 = 12:53.8).

| Время | Часть | План | Текст / эффекты |
|---|---|---|---|
| 0.00–0.60 | чёрный | — | вход из чёрного |
| 0.60–3.56 | **Интро (диалог)** | Бейтман у бара, бирюзовый неон | «TWO STONEY ON THE ROCKS» (белый) → «THESE AREN'T GOOD ANYMORE» (фиолетовый), слова по одному |
| 3.56–7.16 | интро | девушка-бармен (2 ракурса) | «IT'S A CASH BAR», «IT'LL BE $25» (пурпурный) |
| 7.16–10.20 | интро | Бейтман, ухмылка | «YOU'RE A FUCKING UGLY BITCH» (розово-красный) |
| **10.23** | **Дроп** (вход музыки) | крупный план — ухмылка | первый удар: вспышка + зум |
| 10.2–22.8 | **Музыкальная часть** | ~16 планов по **~0.78 с** (на каждый бит, ~77 BPM): ухмылка (2 плана) → расфокус → Бейтман в костюме (наушники) → в офисе → тренировка (пресс/отжимания) → силуэт у жалюзи → лицо в крови → курит (из блюра в резкость) → **повтор блока**: ухмылка → … → курит | на каждой склейке: dip to black (1–2 кадра) + отъезд/наезд Z Dist с моушен-блюром + Twitch-удар + speed ramp |
| 22.8–23.1 | конец | — | затемнение в чёрный |

Провалы в чёрный (средняя яркость < 3 %) измерены на: 10.9, 11.7, 12.5, 13.3, 14.1, 14.9, 15.7, 16.5, 17.2, 18.0, 19.6 с —
шаг 0.78–0.80 с = длина одного клипа. Цвет — ЦК автора (тёмный, контрастный, резкий: близко к **Night CC** / **Two sharp CC**).

## 7. Шаблон для генератора эдита (EffectCraft)

```
[0.0–0.6]  чёрный
[интро]    сцена диалога 8–12 с, 3–4 плана, пословные титры (цвет на фразу) + Glow/Bevel/Shadow + тряска
[дроп]     на первом сильном бите
[музыка]   клипы по 1 биту (0.6–0.8 с); каждый клип:
             timeRemap: 200 % → 30 % → 200 % (F9-кривые, velocity)
             scale: 68 % → 100 % → 68 % от базы (+ motion blur)
             Exposure: +0.4 → −1;  Opacity: 0→100 за 7 кадров, 100→0 за 7 кадров
             тряска: 40 → 0 за 6 кадров
           блок планов можно повторить второй раз
[конец]    затемнение
поверх:    adjustment CC (cc_steps) + adjustment Flicker (интро); motion blur комп. (shutter 360) ≈ RSMB
```
