# aexact — идентичный перенос ЦК «по эталону»

`aefx` переносит **настройки** (что стоит и с какими значениями). Но одинаковые настройки не дают одинаковую
картинку, если сам эффект считает по-другому, а формулы Sapphire / BCC / Magic Bullet Looks закрыты.
`aexact` решает задачу с другой стороны: не угадывает формулы, а **снимает результат с настоящего хоста**
на калибровочных картинках и воспроизводит его собственным движком. Совпадение не обещается — оно измеряется.

```
After Effects ──AEXACT_Capture.jsx──▶ съёмка ──compile──▶ пакет ЦК ──engine──▶ кадры (картинка / видео)
   (плагины стоят там)                 (png)               (таблицы + фильтры)      + отчёт о совпадении
```

## Как это работает

1. **Съёмка.** Пресет применяется к четырём картинкам: `hald` (все 16,7 млн цветов), `hald_shuffled` (те же цвета,
   перемешанные местами), `fit` и `test` (фото). Рендерится весь стек и каждый эффект отдельно.
2. **Разбор.** Если один и тот же цвет даёт один результат в любом месте кадра (`hald` = `hald_shuffled`),
   эффект зависит только от цвета → снимается **полной таблицей**: каждому из 16,7 млн цветов записан ответ хоста.
   Это не приближение — для 8-битного кадра результат совпадает побитово.
   Иначе эффект пространственный (резкость, свечение, размытие) → на `fit` подбирается модель
   (линейный фильтр по 8 масштабам или свечение).
3. **Проверка.** Движок применяет пакет к `test` (в подборе не участвовал) и сравнивает с рендером хоста.
   Вердикт: **ИДЕНТИЧНО** (макс. отличие ≤ 1 уровня из 255), **БЛИЗКО** (99 % пикселей ≤ 3), **ПРИБЛИЖЕНИЕ**.
4. **Применение.** `python3 -m aexact apply <пакет> clip.mp4 graded.mp4` — клип красится движком, потом импортируется
   в EffectCraft как обычный футаж. Движок детерминирован: тот же вход → тот же выход, бит в бит.

## Что доказано (хост — EffectCraft 0.9.2, проверено на сайте)

| ЦК | Состав | Результат на `test` |
|---|---|---|
| цветовой: Hue/Saturation + Curves + Channel Mixer + Photo Filter + Brightness & Contrast | только цвет | **ИДЕНТИЧНО**: макс. отличие 0, все пиксели совпали |
| статичный `night` (4×Unsharp Mask + Unsharp Mask + Exposure + Hue/Saturation) | цвет + резкость | **ПРИБЛИЖЕНИЕ**: среднее 0,95 ур., 99 % ≤ 4, макс. 17 (кадр без ЦК отличается на 20,9 в среднем) |

То есть: **всё, что касается цвета, переносится идентично** — сколько бы эффектов и каких бы плагинов ни стояло
в цепочке, лишь бы результат зависел только от цвета пикселя. Пространственные эффекты переносятся с измеренной
погрешностью.

## Чего система не может и что ей нужно

- **Нужен один прогон в настоящем After Effects** с установленными плагинами — без него снять ЦК автора урока
  неоткуда. `python3 -m aexact kit <папка>` собирает набор (картинки + `AEXACT_Capture.jsx`); в AE:
  File ▸ Scripts ▸ Run Script File. Результат — папка `capture/`, её нужно прислать. Пять ЦК снимаются за минуты.
  **Скрипт в настоящем AE не запускался** (AE здесь нет): проверен только синтаксис. Формат его результата тот же,
  что у проверенной съёмки с EffectCraft.
- **Эффекты, зависящие от места в кадре** (виньетка, градиент, Spot Exposure в Looks) и **нелинейные пространственные**
  (диффузия) точной таблицей не снимаются; модель для них может дать «ПРИБЛИЖЕНИЕ». Отчёт покажет, какой эффект
  и насколько. Magic Bullet Looks целиком — один эффект: если в нём есть диффузия/виньетка, он попадёт сюда.
- Съёмка 8-битная: всё точно для 8-битного конвейера (так рендерит и EffectCraft).
- Анимированные параметры ЦК не снимаются: съёмка — один кадр. Анимацию переносит `aefx`.
- Пакет с полной таблицей весит 10–25 МБ.

## Команды (из `tiktok/effectcraft`)

```bash
python3 -m aexact kit kit/                         # набор для After Effects
python3 -m aexact capture-ec night cap/            # снять ЦК с EffectCraft (имя статичного ЦК или steps.json)
python3 -m aexact compile cap/ pkg/                # съёмка -> пакет + отчёт
python3 -m aexact apply pkg/ in.mp4 out.mp4        # применить (картинка или видео)
python3 -m unittest aexact.tests.test_aexact       # 5 тестов без сети
```

| Файл | Назначение |
|---|---|
| `charts.py` | калибровочные картинки |
| `AEXACT_Capture.jsx` | съёмка в After Effects (скрипт-плагин) |
| `capture_ec.py` | та же съёмка с EffectCraft |
| `compile.py` | съёмка → пакет, подбор моделей, измерение совпадения |
| `engine.py` | движок: таблицы, фильтры, видео через ffmpeg |
