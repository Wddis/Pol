# SysScan: анализ процессов, ядер и ОЗУ (Android 11, без root)

Лёгкое приложение (~590 КБ) на основе официального демо **RikkaApps/Shizuku-API**
(паттерн `UserService`). Через Shizuku оно получает права shell (uid 2000, как у ADB),
поэтому видит **все** процессы: системные, скачанные, демоны и потоки ядра.

## Почему нужен Shizuku
С Android 7+ `/proc` других приложений скрыт (hidepid), а с Android 5.1+
`getRunningAppProcesses()` возвращает только собственный процесс. Обычное приложение
и Termux без root видят только себя. Строка `PROOF:` в логе показывает это наглядно:
сколько процессов видно с shell-правами и сколько без них.

## Установка (Redmi Note 8, MIUI 12.5 / Android 11)
1. Установить **Shizuku** (Google Play или github.com/RikkaApps/Shizuku/releases).
2. Настройки → О телефоне → 7 раз нажать «Версия MIUI» → включить режим разработчика.
3. Расширенные настройки → Для разработчиков: включить «Отладка по USB» и
   «Беспроводная отладка». На MIUI также включить «Отладка по USB (настройки безопасности)»
   и **выключить «Оптимизация MIUI»** (если она блокирует установку/права).
4. Shizuku → «Сопряжение» (Pairing) → в «Беспроводной отладке» нажать «Подключить по коду».
   Ввести код в уведомлении Shizuku → в Shizuku нажать **Start**.
5. Установить `dist/SysScan-1.0.apk` → открыть → «1. Разрешить доступ» → «Разрешить».
6. «2. Анализ» → «3. Скопировать лог» → вставить в чат.

После перезагрузки телефона Shizuku нужно запустить заново (шаг 4, но без сопряжения).

## Termux с теми же правами (для команд оптимизации)
Shizuku → «Использовать Shizuku в приложениях-терминалах» → экспортировать файлы `rish`
в папку → в Termux:
```sh
termux-setup-storage
cp ~/storage/shared/<папка>/rish* ~/ && chmod +x ~/rish
~/rish -c id        # должно вывести uid=2000(shell)
```

## Сборка
```sh
./gradlew assembleRelease   # нужен Android SDK (platform 34)
```
