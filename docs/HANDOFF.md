## 5. Опыт сессии (что ломалось → как правильно)
- **Лимит загрузок канала** общий для API/BrightBean/Studio; 12.11 прошло 8 загрузок без отказа, 11.11 — отказ.
  При отказе Studio пишет «Загрузка недоступна…» — не долбить. Пост BrightBean 1ce9c82f висит «publishing» вечно.
- **Облачный IP**: youtube.com (не Studio) даёт капчу «подозрительный трафик» → лайки/комменты только с телефона владельца.
  Поиск YouTube через yt-dlp: нужен `yt-dlp-ejs` + `--js-runtimes node` + свежие cookies пульта
  (`node tools/yt/export_cookies.js f.txt`), иначе 403/только storyboard.
- **Контейнер перезапускается** (3 раза за 12.11): процессы гибнут, файлы живут. Фоновые задачи — через `setsid nohup`,
  Monitor только читает лог (истекает каждые 30 мин). После рестарта: поднять пульт и `live_update.sh`.
- **Twitch VOD во время эфира** отстаёт на 20–30 мин и растёт кусками — тему видно целиком позже.
- **Whisper**: пакетный режим 27× (docs/whisper.md). Метки конца слов РАНЬШЕ реальных — резать по энергии сигнала.
- **Пульт**: Google отклоняет headless (поле пароля очищается) — только headed Chromium на Xvfb (уже в remote_browser.js).
  По CDP Playwright не передаёт файлы >50 МБ — загрузчик использует DOM.setFileInputFiles (уже в коде).
- **Вебка НИКОГДА не блюрится**. Блюр-боксы на клип (`clip.blur`): разговор «вебка на весь экран» ≠ раскладка браузера.
- **Зум — по смыслу речи**: зум только когда он говорит о своём; если речь про экран (показывает,
  читает, ищет, цены) — без зума (ошибка в Steam Frame 5655–5740). Сила зума: на чёрном/закрытом экране — вебка на весь кадр, f = 1920/ширина вебки, ширину МЕРИТЬ по кадру куска
  (12.11: 693x390 @1227,690 в браузере; 574x323 @1346,757 на чёрном экране → 3.34).
- **Шортсы**: без нижнего текста; TALK-раскладка для «вебка на весь экран»; «?!» требует посимвольный шрифт (сделано).
- **Жёлтая карточка** (docs/no-yellow-card.md): сексуальный контекст в моменте → не в шортс; в названиях без мата.
  Шоу Дипинса и шортс «ЛАПАЛ мужик» получили 18+ от YouTube.
- **Конкуренты** («Т2х2.mp4», «T2x2 Slice») выкладывают те же темы быстро — публиковать основные как можно раньше.
- **Место на диске** ~25 ГБ свободно в начале: 1080p60 ≈ 3,6 ГБ/ч сегментов. Удалять сегменты отработанных участков
  (имя файла = глобальный индекс сегмента ≈ время/10 с) и исходники опубликованных роликов.
- Владелец присылает обложки сам (GPT); мы даём референсы: превью оригинала + крупные эмоции T2x2 + хук-текст.
