## 2. Быстрый конвейер (порядок команд)

Рабочая папка: scratchpad `t2/`. Инструменты: `tools/`.

1. **Аудио всего VOD** (≈1 мин): `python3 tools/vod.py <id> Audio_Only audio.mp4`
   → `ffmpeg -i audio.mp4 -ac 1 -ar 16000 audio.wav`
2. **Видео сегментами в фоне** (≈2 мин, 12 ГБ): `python3 tools/vod.py <id> 1080p60 video.mp4`
   (нужны только сегменты `video.mp4.segs/`; склейку целиком НЕ делать при нехватке диска)
3. **Расшифровка всего стрима** `python3 tools/stt.py audio.wav tr.txt` (в фоне; base, пакетный режим).
   Правила использования (обязательно) — `docs/whisper.md`.
   Замер 11.11 (4 ядра, 600 с аудио): пакетный `BatchedInferencePipeline` bs=16 — 27× реального
   времени против 15,6× у обычного режима (6 ч стрима ≈ 15 мин вместо ~25). Обязательно
   `without_timestamps=False` (иначе сегменты по ~30 с — границы не найти). Модель small — 10×,
   только точечно. Можно резать на куски `stt.py audio.wav out.txt <start> <end>`.
   Пока идёт рендер, расшифровку запускать с `nice -n 19`.
   Параллельно — раскадровка Twitch (sb0) для обзора, но границы по ней НЕ ставить.
4. **Карта событий** по расшифровке: для каждого — начало (подводка/«сейчас
   открою»), конец (переход к другой теме), реклама, пустые донаты, тишина
   (`silencedetect n=-38dB d=6`).
5. **Оригинал видео** для описания: кроп области заголовка YouTube в кадре
   (`crop=1360:180:0:860`) → поиск `yt-dlp "ytsearch3:<заголовок>"`.
6. **Отрезок события**: `python3 tools/vodcut.py <id> 1080p60 video.mp4.segs <start> <end> evX.mp4`
7. **План** `evX_plan.json`: clips (с вырезами), zoom-окна (длинная речь/кульминация,
   ≥5 с, не пересказ экрана), blur (см. ниже).
8. **Рендер** `python3 tools/edit2.py evX.mp4 plan.json OUT.mp4 2` (≈0,5–1× реального времени)
   + превью `scale=640:360,fps=30` (владелец просит 360p30 с 11.11).
9. **QC за 1 минуту**: ffprobe (1920x1080, 60/1), сетка кадров `fps=1/40,tile`,
   громкость ≈ −14 LUFS, стыки.
10. Прислать превью 480p30 + `X_meta.md` → ждать одобрения и обложку.
11. **Заливка** (BrightBean): `social_request_media_upload` → PUT частей по 64 МБ
    (скрипт `up.py`/curl) → `finalize` → обложка тем же путём (картинка, не base64)
    → `social_create_draft` с `delivery: now`, `privacyStatus: public`,
    `thumbnail.assetId`, categoryId 24 → проверять `social_get_post` до `published`,
    смотреть `warnings`.

## 3. Раскладка T2x2 (блюр-боксы 1920x1080)
- `[0,0,262,105]` — плашка слева сверху (донат-сервис/реклама)
- `[1600,18,320,245]` — FONBET/реклама/«по промокоду» справа сверху
- `[1780,815,140,170]` — логотип FONBET на стене за вебкой (раскладка с браузером)
- `[1440,290,165,255]` — FONBET на стене (раскладка «вебка на весь экран»)
- Зум: anchor `[1,1]` (правый нижний угол — вебка+чат), factor 1.5;
  чёрный экран + маленькая вебка → factor 2.5.

## 4. Тайминги (ориентир)
- Аудио VOD: 1 мин; видео-сегменты: секунды–2 мин; расшифровка base (пакетная): ~2,5 мин на час аудио.
- Рендер 1080p60: ~0,5–1× длительности ролика (4 ядра, 2 задания).
- Превью 480p30: ~0,15× длительности.
- Заливка в R2: ~1 ГБ за 30–60 с; публикация YouTube: 1–5 мин.
