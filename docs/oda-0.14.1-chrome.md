# ODA 0.14.1 — исправление Chrome

Предыдущий официальный релиз — ODA 0.12.3. Эта ветка включает изменения из промежуточных сборок и исправление Chrome, которое пользователь проверил на Redmi Note 8 с Android 11.

## Что изменилось

- На стенде Chromium воспроизводил `ERR_CONNECTION_RESET` при обращении к устаревшему адресу из mapdns. На Android 10 и новее ODA сообщает приложениям адрес локального HTTP-прокси Psiphon, когда весь трафик приложений идёт через VPN. Браузер передаёт прокси имя сайта, а прокси отправляет запрос через туннель.
- Локальный прокси принимает стандартные прокси-запросы. Прямой режим Psiphon на этом порту отключён.
- Если исходная сеть явно задаёт HTTP-прокси, ODA передаёт его Psiphon при установлении туннеля.

## Что получилось

- В контрольном тесте после правки Google и тестовый сайт вернули HTTP 200. Попытка воспользоваться прямым режимом прокси вернула HTTP 400.
- После установки опубликованного APK пользователь подтвердил, что Chrome заработал на Redmi.
- На стенде с белым списком контрольный сайт отвечал, а Psiphon не поднял туннель за 35 секунд. Работа на сети оператора под белым списком остаётся неподтверждённой.

Официальный релиз использует тот же проверенный APK. В Android он отображается как `0.14.1-preview` и обновляет ODA Preview. SHA-256 файла — `7b6dd82910d91166dbc181246a3b7d947b2e67275ce4d9c80a667c415cb1906b`.
