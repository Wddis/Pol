# Как составлять ролики, чтобы не получать жёлтую карточку (18+ / ограничения)

Инструкция для каждого ролика канала «Двойная резка / T2x2». Утверждена владельцем 12.11.2026.
Основа: правила YouTube (`docs/youtube-rules.md`). Не отменяет и не урезает базу монтажа
(`docs/montage-style.md`): начало/конец события не режем, вебку не блюрим, монтаж не меняем ради
«безопасности» — работаем метаданными, обложкой и блюром НА ЭКРАНЕ.

Жёлтая карточка в Studio = «Доступно зрителям старше 18» и/или «Ограниченная реклама».
Ставит её автоматика YouTube по: видео (кадры, звук), **названию, обложке, описанию, тегам**.

## 1. На этапе выбора события (по расшифровке, до монтажа)
Оценить риск и сказать владельцу ДО рендера, в сообщении с превью:
| Риск | Признаки в событии | Что делаем |
|---|---|---|
| Сексуальный контекст | тема «кого бы …», откровенные позы/бельё/нюдсы на экране | блюр откровенных кадров на экране; нейтральные метаданные |
| Реальное насилие | бодикамеры, перестрелки, ДТП с пострадавшими, гибель | блюр кровь/тела/ранения на экране; без шок-слов в метаданных |
| Ужасы/кровь из игр/фильмов | «самые кровавые моменты», расчленёнка | блюр крупных планов гора |
| Казино/ставки | стример играет, промокоды, сайты | блюр баннеров/ссылок/промокодов на экране; ни слова в описании |
| Наркотики/опасные трюки | употребление, «челленджи» | блюр/обсудить с владельцем |
| Только мат стримера | — | норма, в видео оставляем (см. п.3: в метаданные мат не выносим) |
Решение «публиковать как есть / смягчить метаданные / не публиковать» — за владельцем.

## 2. В монтаже (без изменения базы)
- Блюр на ЭКРАНЕ (браузер с видео), как и для рекламы: откровенные кадры, кровь/тела, реальные
  жертвы, промокоды/ссылки ставок. Точечно, по времени (blur-окна в плане), не весь ролик.
- Вебку и чат НЕ блюрим. Начало/конец события НЕ режем. Чистка — только по правилам montage-style.
- Не делаем зумы на шокирующие кадры экрана (зум и так только на вебку при речи).
- Пустые донаты с пошлостью без реакции стримера — вырезаются по обычному правилу донатов
  (они ещё и повышают риск); с шуткой-ответом — оставляем.

## 3. Название (самое важное — автоматика читает метаданные)
- БЕЗ мата и его маскировок (*, «бл», «х**»), БЕЗ сексуальных слов («вдул», «чпокнул», «секс»,
  «18+», «голая»), БЕЗ шок-слов («кровь», «труп», «расчленёнка», «убийство» в хуке).
- Хук — эмоция/вопрос стримера: «ЗАЧЕМ ТЫ УБЕГАЕШЬ?!», «ЧТО ТЫ С НЕЙ БУДЕШЬ ДЕЛАТЬ?!».
- Если у оригинала пошлое название — в нашем названии пересказываем смысл нейтрально
  («Монстры, которых он бы выбрал»), а точное название оригинала — только ссылкой в описании.
- Формат прежний: `КАПС-ХУК - суть видео / РЕАКЦИЯ T2x2`, до 100 символов.

## 4. Обложка (её проверяют так же, как видео)
- Без мата, без откровенных поз/белья/частей тела, без крови/трупов/оружия, направленного в камеру.
- Кадр из оригинала — только «безопасный» (для владельца: присылаю безопасный кадр оригинала,
  а не самый шокирующий). Текст на обложке — тот же нейтральный хук.

## 5. Описание и теги
- Описание по шаблону montage-style (оригинал, Twitch, Telegram, SEO-абзац, хэштеги) — нейтральным
  языком: «обсуждает», «реагирует», без пошлых/шок-формулировок и без мата.
- Ссылка на оригинал — обычная ссылка, без цитирования пошлого названия оригинала в тексте.
- Теги и хэштеги: никаких «18+», мата, сексуальных и шок-слов, никаких ставок/казино/промокодов.

## 6. Проверка перед публикацией (Claude, каждый раз)
- [ ] Риск события оценён и сообщён владельцу (п.1).
- [ ] Откровенные/кровавые/ставочные фрагменты на экране замазаны; вебка не тронута.
- [ ] Название, обложка, описание, теги прошли п.3–5 (нет мата/секса/шока/ставок).
- [ ] Видео «Сделано не для детей» — да (канал так настроен); возрастное ограничение вручную НЕ
      ставим (иначе 18+ гарантирован).
- [ ] Не больше 3–4 загрузок в сутки (лимит канала).

## 7. После публикации
- Через 1–24 ч проверить в Studio колонку «Ограничения» (Контент → видео).
- «Доступно зрителям старше 18 (определено YouTube)», если считаем ошибкой → апелляция
  (Studio → Контент → навести на ограничение → «Подать апелляцию»; обычно один раз на видео).
  Перед апелляцией можно заменить обложку/название на более нейтральные.
- «Потенциальный доход ограничен» (Content ID, музыка оригинала) — не страйк, не оспаривать
  без основания (необоснованный спор может обернуться страйком).
- Всё найденное — записать в `docs/youtube-rules.md` (таблица «Что сейчас на канале»).

## 8. Применение к текущим роликам со стрима 08.11 (на согласование владельцу)
- «Монстры…» — сменить название: вместо «Монстры, Которым Бы Я Вдул» нейтрально, напр.
  «ЧТО ТЫ С НЕЙ БУДЕШЬ ДЕЛАТЬ?! - Монстры, Которых Выбрал Бы Кипс / РЕАКЦИЯ T2x2»; убрать тег
  «монстры которым бы я вдул»; обложка без откровенных кадров.
- «4 дикие погони» — проверить кадры бодикамер (кровь/тело погибшего) и замазать на экране, если есть.
- «Душ на подиуме» — по 18+ чисто; отдельный риск — страйк от Земстандарта (решение владельца).
