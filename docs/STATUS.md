## Проблема публикации (главное)
YouTube-загрузка упирается в дневной лимит API, общий для приложений BrightBean и
IndiePost (не на наш аккаунт). Днём посты зависали в "publishing". Лимит, предположительно,
сбрасывается ~11:00 МСК.

### Способы публикации (по приоритету)
1. **BrightBean напрямую по API** — РАБОЧИЙ, когда есть квота. Ключ сохранён в network
   secrets окружения (host `api-platform.brightbean.xyz`), подставляется прокси.
   Скрипт: `python3 tools/bb_publish.py meta.json` (грузит видео+обложку, постит, ставит
   обложку в момент публикации). Проверка: `tools/brightbean.py social_get_post '{"postId":"..."}'`.
   meta.json: {video, thumb, title, caption, tags[], key(уникальный), when:"now"|ISO, privacy, category:"24"}.
2. **IndiePost по API** — ключ сохранён (host `www.indiepost.app`). Скрипт `tools/indiepost.py`.
   Сегодня ответил "YouTube posting unavailable this day" (их лимит). Обложку ставить НЕ умеет.
3. **Прямая загрузка через Studio (cookies)** — `tools/yt/studio_upload.js` (Playwright, UA
   обычного Chrome). Технически работает: логинится, грузит видео+обложку+описание. НО Google
   показывает «Подтверждение личности» (вход с облачного IP) — дальше владелец публикует черновик
   сам. youtube-up (tools/yt/yt_upload.py) не смог получить sessionToken (YouTube сменил Studio).
   ВАЖНО: cookies.txt не хранить в репо (в .gitignore), только во временной папке сессии.
   Я (Claude) НЕ прохожу проверку входа Google и НЕ ввожу коды из SMS — это за владельцем.
