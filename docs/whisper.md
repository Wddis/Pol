# Расшифровка стрима (Whisper) — правила использования

Используется КАЖДЫЙ раз при нарезке стрима. Решение владельца от 11.11.2026.
Порядок работы — `docs/playbook-vod.md`, правила монтажа — `docs/montage-style.md`.

## Что это и чего НЕ делает
- **faster-whisper** (github.com/SYSTRAN/faster-whisper) превращает звук стрима в текст
  с метками времени: `3206.3- 3208.3 Не знаю, я вот один раз в жизни работал с дизайнером…`
- Whisper **НЕ монтирует, НЕ режет и НЕ меняет** видео/звук. Это только «уши».
- Все решения монтажа (начало/конец события, пустые донаты, реклама, зумы, блюр) принимаются
  по `montage-style.md` человеком/Claude, а не Whisper. Никакой автоматической резки по тексту.

## Режим: пакетный (BatchedInferencePipeline) — быстрее без потерь
Скрипт `tools/stt.py` (всё уже зашито):
```
python3 tools/stt.py audio.wav tr.txt                 # весь стрим
python3 tools/stt.py audio.wav tr_part.txt 3000 3600  # кусок (сек)
WM=small python3 tools/stt.py audio.wav spot.txt 4480 4520   # точечная проверка спорного места
```
Параметры: модель `base`, int8, CPU 4 потока, `batch_size=16`, `beam_size=1`, язык ru,
**`without_timestamps=False` — обязательно** (без него сегменты по ~30 с, границы не поставить).

### Замер (11.11.2026, стрим 08.11, 600 с аудио, 4 ядра)
| Режим | Скорость | Сегменты | Слов |
|---|---|---|---|
| обычный base (было) | 15,6× реального времени | 242 | 1580 |
| пакетный base + метки времени (стало) | **27,0×** | 179 (~5 с) | 1567 |
| пакетный base БЕЗ меток | 26,3× | 22 (~27 с) — НЕ годится | — |
| пакетный small | 10,1× | — | — |
- Ни одной фразы обычного режима, на месте которой у пакетного была бы дыра (0 из 242).
  Разница −0,8% слов — мелкие расхождения в словах, не пропуски речи.
- Итог: 6-часовой стрим ≈ 15 мин вместо ≈ 25 мин.

## Правила, чтобы ничего не пропало
1. Расшифровывать **ВЕСЬ стрим** сразу (не только отрезок события) — границы событий по нему.
2. Только пакетный режим **с метками времени** (`tools/stt.py` делает это сам).
3. Whisper коверкает слова («Гогата» = «ГТАшку», «Земстандарт» → «зем стандарт») — искать
   по смыслу и по нескольким вариантам, не по одному ключевому слову.
4. **Каждую границу события и каждый вырез** (донат, реклама) проверять глазами: кадры
   (`ffmpeg … fps=1/…,tile`) и при сомнении — переслушать 1–3 мин моделью `small` (`WM=small`).
5. Длинные паузы в тексте (нет сегментов > 10 с) — это может быть музыка/TTS доната/видео без
   речи; смотреть кадры, а не считать это тишиной для вырезания.
6. Пока идёт рендер — расшифровку запускать с `nice -n 19` (рендер важнее).
7. Модели base и small скачивать заранее (первый запуск сам скачает с HF, ~150/500 МБ).

## Установка (новая сессия)
```
pip install faster-whisper            # версия 1.2.1 = та же, что в GitHub (проверено 11.11)
python3 -c "from faster_whisper import WhisperModel as W; [W(m,device='cpu',compute_type='int8') for m in ('base','small')]"
```
Сборка из GitHub через `pip install git+…` в этом окружении падает (системный setuptools,
`install_layout`). Если нужна именно GitHub-версия: `git clone --depth 1
https://github.com/SYSTRAN/faster-whisper fw-src` и запускать с `PYTHONPATH=fw-src`.
