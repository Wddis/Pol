# Референсы для обложки — СТРОГОЕ правило (владелец, 16.11.2026)

К КАЖДОМУ основному видео вместе с превью отправляется ОДИН и тот же полный набор (не «через раз»):
1. **Обложка оригинала** (`01_original_cover.jpg`, 1280x720) — для реакций ОБЯЗАТЕЛЬНО. ID видео берём
   ТОЧНО как в YouTube (регистр важен: `q6fgVVmdpgY` ≠ `Q6fgVVmdpgY` — ошибка 16.11 дала пустую заглушку).
   Скрипт проверяет, что это не серая заглушка, и ПАДАЕТ, если обложки нет, — нельзя отправить набор без неё.
   Для игры (не реакции) — вместо неё кадры игры (`--game`).
2. **T2x2 — 8 крупных резких кадров вебки** (`02–09`, ×2), разные моменты/эмоции (из 3 соседних кадров берётся самый
   резкий).
3. **Персонаж для вырезки — 4 PNG без фона** (`10–13`, rembg) — готовые к вставке в обложку.
4. **4 кадра экрана** (`20–23`) — что на видео/в игре, без вебки.
5. **Лист-превью** `sheet.jpg` (отправляется картинкой) + архив `<имя>_cover_refs.zip`.

Команда: `python3 tools/cover_refs.py ВИДЕО.mp4 ПАПКА --orig <ссылка/ID оригинала>` (игра: `--game`).
Вебка в другой раскладке — `--cam w,h,x,y` (по кадру). Перед отправкой глазами смотрю `sheet.jpg`:
есть обложка оригинала, лица крупные и резкие, вырезки без «дыр».
