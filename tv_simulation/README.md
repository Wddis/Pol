# Симуляция: YouTube на Samsung без Smart TV с Триколором

Модель проверяет, можно ли получить YouTube на телевизоре Samsung без Smart TV,
к которому подключён приёмник Триколора с Wi-Fi. Перебираются 7 способов
(прошивка Android TV в телевизор и в приёмник, APK на приёмник, homebrew,
Miracast, Android-стик и телефон/ноутбук по HDMI) в трёх сетевых условиях.

Свойства устройств взяты из найденных источников (`facts.py`, у каждого факта
есть ссылка и статус: `confirmed`, `not_found` или `assumption`).

```
python3 -m tv_simulation.simulate                     # прогон, логи в tv_simulation/logs/
python3 -m unittest tv_simulation.test_simulation -v  # тесты
```

Результат: `logs/run.jsonl` (пошаговый лог) и `logs/report.md` (таблица и вывод).

## Ограничения

Это модель, а не эмулятор настоящего железа: она показывает, что следует из
найденных фактов, но не запускает реальные прошивки. Если факты изменятся
(например, появится кастомная прошивка для приёмников GS), поменяйте свойства в
`devices.py`, и результат пересчитается. Тесты `TestModelIsNotRigged` проверяют,
что модель не подгоняет ответ: при «открытых» устройствах прошивка и установка
проходят.

Проверяет ли загрузчик GS подпись прошивки, публично не описано. Но даже без
такой проверки прошивка не встанет: готовых сборок Android под приёмники и
телевизоры Samsung не найдено.
