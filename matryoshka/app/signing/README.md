# Тестовый ключ подписи

`tester.keystore` — ключ, которым подписаны все тестовые сборки Matryoshka начиная с 0.2.0
(SHA-256 сертификата `fc9081168b873e5679fb5f551a9d8d9040faad4107b40050e6889fe047d723c9`).
Он хранится в репозитории по решению владельца: тогда каждая новая сборка (из любой сессии
или из CI) ставится поверх предыдущей, и скачанный образ гостя (1,6 ГБ) сохраняется.

Это **не** ключ для публикации: репозиторий публичный, поэтому подписать этим ключом может
любой. Для публичного релиза нужен отдельный ключ, который хранится вне репозитория
(например, в секретах CI).

Параметры: alias `androiddebugkey`, пароль хранилища и ключа `android`.
