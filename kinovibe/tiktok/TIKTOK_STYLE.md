# TikTok @kinovibetwitch + YouTube Shorts «Фильмы со стримерами» — стиль роликов и конвейер

## Регламент публикации (с 11.11.2026, 01:00 МСК)

Каждый ролик публикуется **одновременно в TikTok и YouTube Shorts** — в одно и то же время (время задаёт владелец, МСК).
`schedule_buffer.py` по умолчанию создаёт оба поста (`SERVICES=tiktok,youtube`). Уже вышедшие в TikTok ролики на YouTube не перезаливаем.
- TikTok: текст = цитата-хук + «Полная запись в био 🍿» + теги.
- YouTube Shorts: заголовок = хук (≤100 символов); описание = хук + «Полная запись — в Telegram: t.me/kinovibetwitch 🍿» + `#shorts` + теги;
  public, категория 24 (Entertainment), не для детей, уведомлять подписчиков.
- Buffer: TikTok `6af35ed662b70b94b0e6430d`, YouTube `6af3934362b70b94b0e99c8d`.

## Стиль ролика (утверждён владельцем 10.11.2026)

- Формат 9:16, 1080×1920, 30 fps, H.264 + AAC. Длина 30–90 с (максимум ~1:40).
- Раскладка (`tiktok_clip.py`):
  - **0–690 px** — вебка стримера (вырез из кадра стрима, растянут на ширину);
  - **690–790 px** — фиолетовая плашка `#9146FF`: «<ник> смотрит «<фильм>»» (Inter ExtraBold);
  - **790–1600 px** — кадр фильма (вырез 4:3 без области вебки);
  - **ниже** — белая плашка «Полная запись — в био» и подпись «КИНОВАЙБ · фильмы со стримерами».
- Субтитры: по словам, по 1–3 слова, капсом, белые с обводкой, **текущее слово розовое** (`#FF3C8C`),
  над нижним краем кадра фильма. **Мат в субтитрах — звёздочками** (`censor()`), звук не трогаем.
- Если стример закрыл экран (обнажёнка), в кадре чёрный фильм — допустимо коротко; обнажёнку в TikTok не выкладывать.
- Моменты — только **реакции стримера** (говорит, смеётся, кричит, комментирует), не просто сцены фильма.
  Никаких полных фильмов и длинных кусков фильма без стримера.

## Подпись к посту

```
<Ник по-русски> смотрит «<Фильм>»: «<цитата из момента>» <эмодзи>
Полная запись в био 🍿

#<ник по-русски> #<login> #<фильм> #стримерысмотрят #реакция #фильм #киновайб #<актёр>
```
Пример: `Зубарев смотрит «Пленницы»: «Ногти, брат, ногти!» 😬` + `#зубарев #zubarefff #пленницы #стримерысмотрят #реакция #фильм #киновайб #хьюджекман`.
Расписание — по указанию владельца (время МСК), между роликами 30–40 мин.

## Конвейер (что реально работает в облачной сессии)

1. **Скачать окно записи из Telegram** (`rdl.js`, запускать через `tg.js run`):
   `MID=<id видео в канале> OUT=part.mp4 FROM_MB=<начало> TO_MB=<конец> node tg.js run rdl.js`.
   - Видео в канале — mp4 с индексом в начале: скачать сначала ~50 МБ от начала (`FROM_MB=0 TO_MB=50`),
     потом нужное окно — ffmpeg читает «дырявый» файл. 15 мин 1440p ≈ 1 ГБ ≈ 11 мин (≈1,6 МБ/с).
   - Индекс (moov) бывает и в КОНЦЕ файла, а звук может лежать в другом месте файла, чем видео того же времени:
     `ffprobe -select_streams a:0 -show_entries packet=pts_time,pos` → докачать нужный диапазон звука.
   - **Только один поток!** Параллельные загрузки (несколько процессов / много запросов к DC файла)
     дают шквал ошибок WebSocket и `AUTH_KEY_UNREGISTERED`.
   - Какие секунды скачались: `ffprobe -select_streams v:0 -show_entries packet=pts_time,pos` по позициям байт.
2. **Расшифровка**: `ffmpeg -ss A -to B -i part.mp4 -vn -ac 1 -ar 16000 win.wav`, затем
   `OFF=A python3 transcribe.py` → `words.json` (слова с таймингом), `lines.json` (фразы).
   faster-whisper `small` int8 на CPU: 16 мин аудио ≈ 1 мин. (`pip install faster-whisper`; аудио читаем через wave/numpy —
   встроенный декодер PyAV в этой среде падает.) Плюс график громкости по секундам — пики = вскрики/смех.
3. **Выбор моментов**: читать `lines.json`, брать места, где говорит стример (не диалоги фильма), 3+ клипа.
4. **Рендер**: `python3 tiktok_clip.py part.mp4 START END clipN.mp4 --cam X,Y,W,H --film X,Y,W,H --title "<Фильм>" --streamer <login> --words words.json`.
   Рамку вебки определить по кадру (`ffmpeg -ss T -i part.mp4 -frames:v 1 f.jpg`). Zubarefff (2560×1440): `--cam 2034,0,526,336 --film 114,0,1920,1440`; dasha228play (1920×1080, вебка слева внизу, чат слева): `--cam 0,780,422,300 --film 440,152,1130,848`.
   Проверить кадры глазами, отправить владельцу на одобрение.
5. **Хостинг для Buffer** (Buffer берёт видео только по публичной ссылке):
   - работает **uguu.se**: `curl -F "files[]=@clip.mp4" https://uguu.se/upload` → `url`; файл живёт **~3 часа** —
     публикации должны попасть в это окно; для поздних постов — загрузка ближе ко времени (напоминание через send_later);
   - catbox.moe / litterbox — 403 для этого сервера, 0x0.st и tmpfiles.org — обрыв соединения, pixeldrain — нужен ключ.
   - Альтернатива: FastClip (`.mcp.json`) отдаёт публичный `download_url`, но импортирует видео только с YouTube/X/Twitch/Google Drive.
6. **Расписание**: `python3 schedule_buffer.py plan.json` (время МСК, сразу TikTok + YouTube) → проверить очередь (оба канала):
   `../buffer.sh 'query($o: OrganizationId!){ posts(input:{organizationId:$o, filter:{channelIds:["6af35ed662b70b94b0e6430d","6af3934362b70b94b0e99c8d"]}}, first: 10) { edges { node { id status dueAt text } } } }' '{"o":"6af35dd6f71fd9215f39b2bf"}'`.
