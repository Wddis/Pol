# КиноВайб — стиль канала @kinovibetwitch

Канал с записями стримов Twitch, где стримеры смотрят фильмы и сериалы.
Этот файл — эталон оформления. Каждый новый пост приводится к нему.

## 1. Подпись к посту (HTML parse mode)

```html
🎬 <b>Название фильма</b> (Год)

🎙 Стример: <a href="https://www.twitch.tv/LOGIN"><b>DisplayName</b></a> #login
🏁 Ивент: #киногонка — сезон 5, день 5            ← только если это ивент
📅 Стрим: ДД.ММ.ГГГГ                               ← только если дата известна
🎭 Жанр: #жанр1 #жанр2 #жанр3
⏱ Фильм: 1 ч 49 мин · запись: 2 части по 1 ч 40 мин
▶️ Начало фильма: 1:06:50 (1-я часть)              ← только если тайминг известен
⭐ IMDb 7.4 · Кинопоиск 8.1

<blockquote>Описание без спойлеров, 2–4 предложения. В конце — главные актёры / режиссёр / награды.</blockquote>

💬 Делитесь впечатлениями в комментариях

#фильм
```

Правила:
- **Эмодзи в заголовке** — тематический под фильм (⚖️ суд, 🐻 «Выживший», 🪚 «Бензопила», 🎰 Вегас…).
- **Ник стримера** — точный Twitch login/displayName, проверенный через Twitch (см. ниже). Ссылка на канал + хэштег латиницей в нижнем регистре.
- **Описание** — всегда цитатой (`<blockquote>`), без спойлеров.
- **Не писать** про «общественное достояние» и прочие юридические пометки.
- Итоговые хэштеги: `#фильм`, `#сериал`, `#мультфильм`, `#аниме`; серии — свой тег (`#богатыри`).
- Если в исходной подписи неверный год — исправить по базе (пример: «Выстрел в пустоту» → 2017).

## 2. Обложка видео

Генерируется `cover.py` (Pillow, шрифты Inter / Inter Display), 1280×720.

- Фон: диагональный градиент `#2E125C → #08070E`, свечения фиолетовое `#9146FF` (справа сверху) и розовое `#FF3C8C` (слева снизу), лёгкое зерно.
- Слева сверху: квадратик `#9146FF` + **КИНОВАЙБ** + «фильмы со стримерами».
- Справа сверху (для альбомов): белая плашка «ЧАСТЬ N ИЗ M».
- Розовая контурная плашка ивента (если есть): «КИНОГОНКА · СЕЗОН 5 · ДЕНЬ 5».
- Название — Inter Display Black, капсом, до 3 строк, кегль подбирается автоматически; под ним «Год · жанры».
- Блок ивент + название + мета центрируется по вертикали.
- Внизу: фиолетовая плашка с микрофоном «СТРИМЕР / ник», бейджи **IMDb** (жёлтый `#F5C518`) и **КП** (оранжевый `#FF6600`).
- Справа: полоса киноплёнки и фиолетовая кнопка ▶.

Пример: `covers/example.jpg`.

Каждой части альбома — своя обложка. Первой части, если известен тайминг начала фильма,
ставится `video_timestamp` (поле `start` в posts.json, в секундах) — видео сразу стартует с фильма.

## 3. Закреп и каталог (страница Telegraph)

- Каталог всех записей — **одна страница Telegraph**: https://telegra.ph/KinoVajb--katalog-zapisej-11-10
  (стримеры по числу записей; у каждого — Twitch, тег, разделы: сначала франшизы, затем «🎬 Фильмы», «🎨 Мультфильмы и аниме», «📺 Сериалы»;
  внутри по году: `Название (год) · ⭐ IMDb`, название — ссылка на пост). Отдельных постов-каталогов в ленте нет.
- В закрепе (id 4) блок «📚 Каталог записей»: ссылка на страницу + ники со ссылками на их разделы (`#якорь`) и число записей.
- После каждой партии:
  1. `STAGE=collect node tg.js run catalog_page.js` → `catalog_data.json`;
  2. `python3 telegraph_page.py` → обновляет страницу (тот же адрес), пишет `page.json`;
  3. `STAGE=pin node tg.js run catalog_page.js` → обновляет блок в закрепе.
- Токен Telegraph — `~/.kinovibe_telegraph.json` (НЕ в репозитории: репозиторий публичный, токен даёт право править страницу).
  Если токен потерян — скрипт создаст новую страницу; затем шаг 3 переставит ссылку в закрепе.
- Новая франшиза → добавить хэштег и заголовок в `SERIES` (`catalog_page.js`).

## 4. Порядок работы с новым постом

1. Найти пост(ы) в канале, собрать части альбома.
2. **Стример**: найти источник (каналы папки Twitch — совпадение по `document.id` или названию),
   проверить ник через Twitch GQL (`user(login:"…"){displayName followers{totalCount}}`).
   Не угадывать — если не подтверждён, спросить владельца.
   Канал @twitch_vods публикует журнал стримов с заголовками — там видно название и год фильма.
3. **Рейтинги**: Kinopoisk id через Wikidata (P2603 по IMDb id P345 или по русскому названию),
   затем `https://rating.kinopoisk.ru/<kp_id>.xml` → kp_rating и imdb_rating. Длительность — Wikidata P2047.
4. Отредактировать подпись по шаблону (§1).
5. Добавить запись в `posts.json`, `python3 make_covers.py <ids>`, затем `ONLY=<ids> node tg.js run apply_covers.js`.
6. Пересобрать каталоги: каталог (`catalog_page.js` collect → `telegraph_page.py` → `catalog_page.js` pin).
7. **Комментарии**: проверить `message.replies.comments`. Telegram создаёт ветку только для первого
   поста в «пачке» — посты нужно публиковать с паузой 10–15 с. Если ветки нет — перевыложить пост
   (тот же document по id, та же подпись, `silent`), дождаться ветки, затем удалить старый и поправить ссылку в навигаторе.

## 4a. Быстрый путь (скрипты)

1. Описать новые посты в `new.json` (формат — в шапке `style_posts.js`).
2. **Пересланные посты** (с плашкой «Переслано из…») редактировать нельзя →
   `node tg.js run repost_styled.js` — перевыкладывает их как наши (тот же файл, наша подпись, без звука),
   ждёт ветку комментариев, удаляет оригинал и обновляет id в `new.json`.
3. `node tg.js run style_posts.js` — подписи (для своих постов) и запись в `posts.json`.
   Затем каталог (`catalog_page.js` collect → `telegraph_page.py` → `catalog_page.js` pin) — каталоги стримеров и закреп.
4. `python3 make_covers.py <ids>` → проверить картинки → `ONLY=<ids> node tg.js run apply_covers.js`.

Любое сообщение ограничено 4096 символами — `catalog_page.js` (STAGE=pin) печатает длину закрепа.

## 5. Технические данные

- Канал: @kinovibetwitch, группа обсуждения: «КиноВайб | Обсуждение фильмов со стримерами» (в неё никого не приглашать).
- Клиент: `tg/tg.js` из ветки `ccr-a37e2040-aq2eun` (GramJS через WebSocket). Ключи `TG_API_ID`/`TG_API_HASH`
  и `session.txt` **не коммитить**.
- Скрипты здесь запускаются как `node tg.js run <script.js>` из папки, где лежат `posts.json` и `covers/`.

## 7. Несколько фильмов в одном посте

Если в посте/альбоме несколько **разных** фильмов (например, «Тачки 1–3») — каждый фильм отдельным постом
со своей подписью и обложкой. Части **одного** фильма остаются одним альбомом.
Чтобы сохранить порядок в ленте, перевыкладываются все посты начиная с первого разделяемого:
`REPOST_FROM=<id> node tg.js run repost_styled.js` (каждому фильму — свой элемент в new.json с id его видео).
У франшиз — общий хэштег серии в последней строке: `#человекпаук`, `#тачки`, `#достатьножи`, `#великийуравнитель`…

## 8. Совместные просмотры и мусор в исходных подписях

- Несколько стримеров: основной — в строке «🎙 Стример», остальные — строка «🤝 Вместе с: …» (поле `ft` в new.json).
- Из исходных подписей не переносить служебные пометки («Урезанное качество», «урезка», ссылки на чужие каналы).
- Опечатки ников исправлять по Twitch (пример: «AhniNyan» → AhriNyan). Имя в файле может не совпадать со стримером
  (источники переименовывают) — верить подписи источника, дату стрима брать из имени файла только если ник в нём совпадает.
