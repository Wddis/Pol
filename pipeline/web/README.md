# Двойная резка — локальная панель

Запуск из `pipeline/web`:

```sh
uv venv /workspace/t2x2/.web-venv
uv pip install --python /workspace/t2x2/.web-venv/bin/python -r requirements.txt
/workspace/t2x2/.web-venv/bin/uvicorn server:app --host 127.0.0.1 --port 8787
```

Открой http://127.0.0.1:8787 на машине сервера. Для телефона нужен существующий защищённый прокси до сервера. Не публикуй порт без аутентификации. По умолчанию воркер использует Python из `/workspace/t2x2/.venv`; переопределение через `T2X2_WORKER_PYTHON`. Задачи хранятся в `T2X2_WEB_DATA` или `/workspace/t2x2/web-jobs`. Используй один экземпляр Uvicorn.

Каталог и live-статус запрашиваются через yt-dlp. Если Twitch не подтверждает live-статус, в панели статус неизвестен. Live-захват ограничен 15 минутами и начинается с текущего момента. Карта строится эвристиками по тексту, её границы и тип нужно подтвердить. Один монтажный эпизод на задачу, без внутренних удалений. Выдача мастера проверяет статус пайплайна. Техника для проверки масок и цензуры остаётся в существующих артефактах задачи. Вертикальный экспорт использует весь кадр и аудио готового мастера.

## Защищённый домен

В Cloudflare нужен активный домен. Настрой self-hosted Access на весь поддомен с политикой входа по email и именованный Tunnel до `http://127.0.0.1:8787`. До запуска коннектора подготовь секреты среды. Не добавляй их в Git и не передавай через параметры URL.

- `T2X2_PUBLIC=1`
- `T2X2_PUBLIC_HOST` — публичный поддомен полностью.
- `T2X2_ACCESS_TEAM` — адрес команды вида `team.cloudflareaccess.com`.
- `T2X2_ACCESS_AUD` — AUD приложения Access.
- `T2X2_ACCESS_PIN` — код второго шага.
- `T2X2_SESSION_KEY` — отдельное случайное значение от 32 байт.

На стороне FastAPI проверяются подпись JWT Access, issuer, audience и срок, затем PIN-сессия. Авторизация применяется и к API, и к видео. При выключенном публичном режиме приложение отклоняет внешние имена хостов. В публичном режиме браузер каждые 45 секунд переподключает поток событий, при этом задача продолжает выполняться.

## Бесплатный ngrok

Укажи в секретах `NGROK_AUTHTOKEN` и отдельный случайный `T2X2_NGROK_PASSWORD` длиной не менее 20 символов. Установи `T2X2_NGROK=1` и `T2X2_PUBLIC_HOST` в точный выданный ngrok адрес без HTTPS. Режим Cloudflare должен быть выключен. Запусти Uvicorn на loopback с этой конфигурацией, затем `ngrok http --url "https://$T2X2_PUBLIC_HOST" --inspect=false http://127.0.0.1:8787`. Перед передачей ссылки проверь, что без пароля панель и API возвращают 401. Логин — `t2x2`. Origin-заголовок изменяющих запросов должен совпадать с HTTPS-адресом.

Внешний режим ngrok не отдаёт видео, чтобы не расходовать месячный лимит бесплатного тарифа. Результаты остаются в папке задачи для отдельной выдачи или публикации по команде владельца.

## Cloudflare Workers без туннеля

Worker `t2x2-montage` принимает команды панели и хранит статусы в SQLite Durable Object `Relay`. Публикуемые модули — `relay.js` и `page.js` с мобильным интерфейсом, адаптированным под опрос. На Worker необходимы секреты `PANEL_PASSWORD`, `AGENT_SECRET` и binding `RELAY`. Логин браузера — `t2x2`. Прямой доступ к локальному FastAPI остаётся на 127.0.0.1:8787.

При запуске `relay_agent.py` из этой папки задай в окружении `T2X2_RELAY_URL` и `T2X2_RELAY_SECRET` (то же значение, что `AGENT_SECRET`). Разрешён только один активный агент на панель. Он опрашивает Worker, обновляет статусы и выполняет только команды каталога, анализа, рендера, повторных попыток и Shorts. Потеря ответа на команду не приводит к её автоматическому повтору: перед повторной отправкой проверь список задач. При остановке Codex сохраняются последние состояния, но локальные команды требуют запущенной среды. Мастера не передаются через Worker.

## Возобновление панели

Запусти `./start-panel` из папки `web` и оставь процесс под управлением среды Codex. Секрет агента читается из `~/.config/t2x2/relay-secret` или файла из `T2X2_RELAY_SECRET_FILE`. Телефон можно отключить. После остановки среды запусти эту же команду: очередь и готовые промежуточные файлы сохраняются в `T2X2_WEB_DATA`. Прерванный захват эфира требует подтверждения нового диапазона.

Публичный Worker использует `relay.js` и `page.js`. При изменении `index.html` обнови экспорт HTML в `page.js` перед публикацией Worker. Одна и та же страница работает напрямую с локальной панелью и через Cloudflare.

### Покадровая проверка баннеров

Для исправления отдельной нарезки сохраните `montage/mask-review.json` в каталоге задачи. Укажите SHA-256 файла `hd.mkv` (или исходника живого захвата), точный `keep` из EDL и проверенные поправки. В `overrides` ключи — индексы видеочастей после интро, начиная с 1, значения — локальные файлы покадровых масок в каталоге `montage`. В `verified_absences` ключи первого уровня тоже индексы частей, второго — номера кадров внутри части с 0. Значение — список проверенных сторон `left` и `right`. Отмечайте отсутствие только после просмотра конкретных кадров. При повторе пересобираются части с исправленными масками. Проверка речи и громкости выполняется по итоговому файлу.

### Референсы, склейки и модель баннеров

`./install-banner-model` скачивает веса OpenCV ViTTrack (Apache-2.0, CPU) и сверяет SHA-256. Версия модели входит в ключ видеочанка. При подтверждённом шаблоне модель подхватывает баннер при срыве детектора. Результат должен совпасть с геометрией ранее измеренного баннера и поддерживаться пикселями текущего кадра. Остальные случаи сохраняются для QA.

В форме эпизода можно задать несколько пауз на удаление. Координаты указываются по VOD. Панель отклоняет вырезку, пересекающую слова транскрипта. Донаты сохраняются. Для точечной правки звука после QA укажи подтверждённые окончания слов, каждый интервал до 1,6 секунды. При прежнем EDL видео берётся из кеша. В карточке доступны кадры исходника и результата с таймкодами.

### Локальный редактор стрима

`./install-editor-model` устанавливает проверенную сборку llama.cpp и Qwen2.5-1.5B-Instruct Q4_K_M. Файлы занимают примерно 1,1 ГБ и проверяются по SHA-256. Запуск панели поднимает модель на loopback и поднимает её заново при сбое. Внешний API или ключ для запросов не нужен. Вопросы выполняются очередью. Редактор получает выборку реплик и подтверждённые кандидаты, а ответы сохраняются вместе с задачей. Рендер запускается кнопкой после подтверждения границ.

«Реакция» ищет начало просмотра и финальную реплику и сохраняет целый эпизод. При неизвестных границах нужен ручной выбор. «Shorts» экспортирует выбранный эпизод в вертикаль без интро после отдельной проверки. «Короткое видео» сохраняет выбранную сцену в обычном формате. Проверенный пример берётся из VOD 2929609163 и архивного плана.

Команда `SearchCode opencv TrackerVit` ищет код OpenCV. Доступны также `llama` и `ffmpeg`. Этот запрос отправляет SearchCode только явно введённое поисковое выражение и адрес выбранного репозитория. Вопросы о содержании, расшифровка и видео обрабатываются локально.
