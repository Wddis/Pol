SearchCode подтвердил `word_timestamps` и `vad_filter` в faster-whisper, а также реализацию CSRT в opencv_contrib. Дополнительный MCP для локального монтажа не требуется. Для повторной выгрузки опубликованных метаданных нужен сетевой маршрут к YouTube, на котором `yt-dlp` открывает страницу или API. Для платформенных ограничений и Content ID нужен просмотр YouTube Studio владельцем после ручной загрузки. Местный сигнал по музыке не предсказывает решения Content ID.

## Найденные обёртки

В прежней системе Telegram-обработчики `tools/tgbot/smart.py`, `bot.py` и `brain.py` управляли VOD, картой и заданиями. `make_main.sh` вызывал нарезку, детекторы, `edit2.py`, нормализацию, цензуру и добавление интро. В той версии баннеры брались из объединённого бокса по выборке. Рекламу в чате обрабатывал `chat_promo_mask.py`. Проверка локального Shorts дала 1080×1920 и 2,000 с видео на тестовом интервале 24–26 с. Старый `check_video` в Studio мог заглушить заявленную музыку. Локальная проверка работает с файлом, итог Studio проверяет владелец.
