# Контрольная пересборка и CLI

1. Сверить архивный монтажный план с видео и аудио VOD, привязать интро, склейки, цензуру и главы к исходнику и готовому MP4.
2. Сохранить нумерованную карту и EDL. Хранить решения о цензуре и маски отдельно. Проверить перенос таймкодов через удалённый интервал.
3. Использовать архивные ассеты и генератор интро. Для баннеров пересчитывать положение по изображению на каждом выходном кадре. Сначала собрать черновик и проверить маски.
4. Собрать контрольный финал с параметрами измеренного эталона. Проверить длительность, главы, уровни, распознавание и местные признаки возрастного ограничения. Сохранить материалы для ручной публикации.
