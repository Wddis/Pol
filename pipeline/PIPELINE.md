# Дерево монтажа T2x2

Видео и звук передаются через файлы. Статус этапа и время хранятся в run.json. Координаты плана относятся к исходнику. GPU-воркеры запускаются последовательно.

LOCATE (1–25 с на метаданные, загрузка по скорости HLS)
→ ANALYZE (параллельно ASR/VAD около 10–25 с на минуту, обзор кадра и алертов 5–20 с)
→ JUDGE (компактные фрагменты и локальный либо API-рецензент, оценка 5–30 с)
→ PREPARE (параллельно маски и заготовка звука с цензурой, интро из архива, 10–40 с на минуту видео)
→ RENDER (кешированное видео и один AAC, вывод основной и уменьшенной версий, 10–45 с на минуту)
→ QA (параллельно контроль кадров, ААС и повторная проверка речи, 10–35 с на минуту)
→ META (до секунды после получения редакторских полей) → DELIVERY → условная PUBLISH.

Для первого запуска используется локальная редактура по транскрипту и контактной сетке. Автономный режим использует Gemini-адаптер из исторической ветки. Для проблемных границ редактор получает точную причину. Оценки времени предварительные.

Приёмка: исторический план и 29 исходных окон, блокировка при плохом QA, одинаковые кадры и AAC в двух файлах, повторный запуск по сохранённым результатам, отдельная живая запись.
