# Возобновление монтажа

Работа приостановлена по просьбе владельца. Ветка сохраняет прежнюю монтажную систему и новую папку `pipeline/`. В ней скрипты, версии зависимостей, EDL, реестр, инструкции, контрольные измерения и черновые редакторские планы. Сырьё, рендеры и доступы хранятся отдельно.

Основное интро: `../assets/intro/intro_t2x2.mp4` (синяя пиксельная аватарка, 10 с, 1080p60; SHA-256 `a58ae08343fa25f300cff9b6c6391c60f191b1d65b4e92ba776f07eecae87119`). Пайплайн и `clip new_intro` берут его по умолчанию. `restore-assets.sh` возвращает старую версию только для сравнения с эталоном; архивные EDL остаются привязаны к ней.

## Подготовка после возобновления

Из корня этой ветки перейти в `pipeline/`. Нужны Python 3.12, FFmpeg/FFprobe и Tesseract. Venv предыдущей сессии создаётся из `requirements.lock`.

```sh
cd pipeline
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
./restore-assets.sh
.venv/bin/python clip doctor
.venv/bin/python -m unittest -q test_pipeline
```

Модель Faster-Whisper small может быть скачана при первом распознавании. Для длинных транскриптов `pipeline_speech.py` также использует base. Для отдельного эксперимента с вырезом головы нужен `rembg[cpu]` и модель U²-NetP. Переиспользуемые исторические скрипты лежат в `../tools`.

## Регрессия

Эталонный MP4 положить в `evidence/reference.mp4`. Контрольная сумма в `evidence/reference.sha256`. Сырой интервал VOD 2929609163 загрузить в 720p60 от 6010 до 6550 с. Рабочее имя для реестра — `evidence/vod-720p60.mp4`. Если новый файл уже имеет локальную нулевую шкалу, его можно поместить по этому пути, учитывая ожидаемый сдвиг реестра 6010. Для общей загрузки диапазонов используется `pipeline_source.py` с локальным JSON, полученным через yt-dlp. JSON может содержать временные URL и остаётся локальным.

```sh
.venv/bin/python clip run "проверка эталона" --regression --job runs/reference
```

Архивный прогон собрал две версии. Релиз удержан QA из-за кандидатов в расшифровке и проверки покрытия масок. См. `checkpoints/regression-report.txt` и `checkpoints/regression-qa.json`. Режим сохраняет исторический разрез, 29 окон и тишину в концовке. Предыдущая вручную проверенная пересборка описана в `MONTAGE.md`.

## Последнее состояние

Последний выбор владельца перед паузой — дождаться игры в текущем эфире t2x2. На последней проверке Twitch VOD 2940338302 длился 1:03:07, вся доступная часть была в категории Just Chatting. Выпуск на 59 минут из текущего эфира не собран. Архивный план после `ItLukaVulis` сохранён в `checkpoints/archive-gta-after-part-4.draft.json` как черновик. Вторую границу технической паузы нужно повторно проверить: около 12933,83 с начинается реплика.

Автономной редактуре нужен `GEMINI_API_KEY`. Можно передать проверенный локальный план через `--plan`. Публикация остаётся за владельцем до явной команды. Для работы загрузчика нужны YouTube OAuth с правом загрузки и локальные файлы `yt_client.json` и `yt_token.json` в каталоге, заданном через `T2X2_YOUTUBE_OAUTH`. Подтверждение возрастной отметки и Content ID выполняется в Studio.
