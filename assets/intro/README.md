# Интро канала «Двойная резка / T2x2»

Правило (владелец, 12.11.2026): интро ставится в начало КАЖДОГО НОВОГО ОСНОВНОГО видео. Shorts — без интро.

## ОСНОВНОЕ — «Ретро-ТВ» (утверждено владельцем 12.11.2026 вечером)
- `intro_t2x2.mp4` — готовое интро «Ретро-ТВ»: 1920x1080 @ 60 fps, H.264 High yuv420p (CRF 21, maxrate 30M),
  AAC 48 kHz stereo 256k, **10,0 с**, −14 LUFS, ~39 МБ. Ставить: `tools/add_intro.sh T2x2_X.mp4 T2x2_X_intro.mp4`
  (склейка без перекодирования — параметры совпадают с рендером `edit2.py`, проверено на ролике Верити).
- Сценарий (10 с): телевизор включается из полоски → голова говорит «**Ой, ну что, здравствуйте, ребята!**» (эхо
  гаснет) → помехи «CH 01» → **CH 01** «T2X2 · АНТОН / реакции, игры и общение с чатом» + фраза «**Ладно, всё, поехали!**»
  → помехи → **CH 02** «twitch.tv/T2X2» — БЕЗ фразы (владелец убрал «Давай, давай») → помехи → **CH 03** «Больше
  нарезок на канале «Двойная резка»» + фраза «**Красота вообще!**» → телевизор выключается в точку.
- Анимация (плавно, в меру): голова выезжает сбоку на каждом канале, «дышит» и шевелится в такт своей фразе; строки
  выезжают с проявлением и печатаются по буквам (телетекст, зелёный курсор); иконки twitch/канала «пружинят»;
  медленный наезд на фон; после переключения канала — «соскальзывание» кадра по вертикали.
- Эффекты: выпуклый кинескоп со скруглёнными углами, свечение (bloom), строки развёртки и мерцание, цветное двоение
  (сильнее на голосе), VHS-полоса, блик по стеклу, OSD «▶ ВОСПР.», «CH 0x», таймкод. Шрифт Russo One.
- Звук: всё синтезировано (синтвейв 112 BPM, помехи, «телетекст», включение/выключение ТВ) — Content ID не сработает;
  под фразами музыка приглушается. Фразы — голос стримера с мягким эхом, затухает только хвост эха.
- Файлы: `tv/ph1_poehali.wav` (VOD 2926718724, 10392.80–10394.15), `tv/ph3_krasota.wav` (12938.25–12939.45),
  `voice_privet.wav` (VOD 2924895000, 254.55–256.50), `head_t2x2.png`, `avatar_channel.png`.

Пересобрать (нужны шрифты russo-one cyrillic+latin woff в `fonts/`: `npm pack @fontsource/russo-one@5.3.0`):
```
python3 tools/intro/make_intro_tv.py assets/intro/head_t2x2.png assets/intro/avatar_channel.png fonts \
  assets/intro/voice_privet.wav assets/intro/tv/ph1_poehali.wav - assets/intro/tv/ph3_krasota.wav intro_raw.mp4
ffmpeg -i intro_raw.mp4 -c:v libx264 -preset slow -crf 21 -maxrate 30M -bufsize 60M -pix_fmt yuv420p -profile:v high -r 60 \
  -c:a aac -b:a 256k -ar 48000 -ac 2 -video_track_timescale 15360 -movflags +faststart assets/intro/intro_t2x2.mp4
```
(`-` вместо файла фразы = канал без фразы. Рендер ~5 мин на 4 ядрах. Без пережатия файл ~150 МБ из-за помех —
в git не влезает.) Новая фраза: `python3 tools/intro/make_voice.py audio.wav START END out.wav 0.9` — границы по
ЭНЕРГИИ сигнала, проверка расшифровкой сухого куска (с эхом whisper путается — это нормально).
