# Android Chrome MCP

Claude работает в **вашем Chrome на Android в фоне**, а вы пользуетесь телефоном как обычно: смотрите YouTube, переписываетесь и так далее. Схема похожа на Telegram MCP через my.telegram.org: Claude работает через API самого Chrome (DevTools Protocol), а не через экран.

```
Claude (приложение или claude.ai)
        │  HTTPS (секретный адрес)
        ▼
Cloudflare-туннель ──► MCP-сервер в Termux ──► adb (телефон сам к себе) ──► DevTools сокет Chrome
```

**Что Claude видит:** только Chrome. Экран, уведомления, другие приложения и файлы ему недоступны: в сервере нет ни одной команды для них.
**Какие вкладки:** по умолчанию только вкладки, которые Claude открыл сам. Ваши вкладки скрыты, пока вы не включите `chrome-mcp user-tabs on`.
**Аккаунты:** Claude работает в вашем профиле Chrome, поэтому ваши входы на сайты ему доступны.

## Установка (один раз, примерно 10 минут)

**Нужно:** телефон с Android 11 или новее, Wi-Fi на время первой настройки, приложение **Termux** с [F-Droid](https://f-droid.org/packages/com.termux/) или [GitHub](https://github.com/termux/termux-app/releases). Версия Termux из Google Play устарела и не подходит.

### 1. Termux
Откройте Termux и вставьте:
```bash
curl -fsSL https://raw.githubusercontent.com/wddis/pol/main/android-chrome-mcp/install.sh | bash
```
Если ветка `main` ещё не обновлена, используйте эту команду:
```bash
curl -fsSL https://raw.githubusercontent.com/wddis/pol/ccr-53c32ce8-hewh3l/android-chrome-mcp/install.sh | bash
```

### 2. Режим разработчика (Xiaomi / HyperOS / MIUI)
1. Откройте **Настройки → О телефоне** и 7 раз нажмите на **«Версия HyperOS»** (или «Версия MIUI»).
2. Откройте **Настройки → Доп. настройки → Для разработчиков** и включите:
   - **Отладка по USB**. Кабель не нужен, но без этого Chrome не откроет свой API.
   - **Отладка по Wi-Fi**.

### 3. Сопряжение телефона с самим собой
Откройте Termux и Настройки **в разделённом экране**, иначе окно с кодом закроется. В Termux:
```bash
chrome-mcp setup
```
В Настройках откройте **Отладка по Wi-Fi → Подключение с помощью кода** и введите в Termux порт и 6-значный код.

### 4. Чтобы Xiaomi не закрывал фоновые процессы
Для **Termux** и для **Chrome**:
- **Настройки → Приложения → (приложение) → Автозапуск**: включить.
- **Контроль активности** (батарея): **Нет ограничений**.
- Для Termux ещё: в списке недавних приложений зажмите его карточку и нажмите **замок**.

## Каждый день

```bash
chrome-mcp start
```
Команда выведет адрес такого вида:
```
https://xxxx-xxxx.trycloudflare.com/mcp/3f9c...e1
```

**Первый раз**, а также после перезагрузки телефона или `chrome-mcp stop`:
откройте **claude.ai → Настройки → Коннекторы → Добавить свой коннектор** (Add custom connector), вставьте адрес, OAuth-поля оставьте пустыми и сохраните.
Мобильное приложение Claude само коннекторы не добавляет. Откройте claude.ai в браузере телефона, а потом коннектор появится и в приложении.

После этого просто пишите Claude, например:
> Открой в моём Chrome сайт ozon.ru, найди беспроводные наушники до 3000 ₽ с рейтингом от 4,8 и пришли 5 лучших со ссылками.

Termux можно свернуть и пользоваться телефоном: Claude работает в фоновой вкладке Chrome.

| Команда | Что делает |
|---|---|
| `chrome-mcp start` | запустить и показать адрес |
| `chrome-mcp stop` | остановить всё и закрыть доступ |
| `chrome-mcp status` | что сейчас работает |
| `chrome-mcp url` | показать адрес ещё раз |
| `chrome-mcp logs` | логи, если что-то не так |
| `chrome-mcp new-secret` | сменить секрет; старый адрес перестанет работать |
| `chrome-mcp user-tabs on/off` | разрешить или запретить доступ к вашим вкладкам |

## Что умеет Claude

`navigate`, `snapshot` (чтение страницы с пронумерованными кнопками и полями), `click`, `type` (с отправкой формы), `select_option`, `press_key`, `scroll`, `wait_for`, `screenshot`, `evaluate` (JavaScript на странице), `tab_open`, `tab_select`, `tab_close`, `tabs_list`, `history` (назад, вперёд, обновить), `browser_status`.

## Важно знать

- **Новая вкладка.** Chrome на Android не даёт открывать вкладки через API, поэтому новая вкладка открывается через Intent. Chrome мелькнёт примерно на секунду, после чего сервер сам вернёт приложение, которое было открыто до этого. Обычно Claude работает в одной вкладке, и такое случается редко.
- **Скриншоты фоновой вкладки** на Android могут не получиться. Claude по умолчанию читает страницу текстом, это дешевле.
- **Без Wi-Fi.** После `chrome-mcp start` adb переходит в режим `127.0.0.1:5555` и работает без Wi-Fi, но только до перезагрузки. После перезагрузки нужен Wi-Fi, чтобы снова выполнить `chrome-mcp start`.
- **Адрес меняется** при каждом новом запуске туннеля: после перезагрузки или `stop`/`start`. Пока туннель работает, адрес тот же. Постоянный адрес можно получить через свой Cloudflare-туннель: в `~/.android-chrome-mcp/config.env` задайте `ACM_CF_TOKEN` (токен туннеля из Cloudflare Zero Trust, тип *cloudflared*, сервис `http://127.0.0.1:8765`) и `ACM_PUBLIC_URL=https://ваш-домен`.

## Безопасность

- Адрес коннектора работает как пароль: в нём 48-символьный случайный секрет. Не публикуйте его. Если адрес утёк, выполните `chrome-mcp new-secret`.
- Пока сервер запущен, любое приложение на телефоне может подключиться к Chrome через `127.0.0.1:9222`. Не запускайте сервер, если не доверяете установленным приложениям. `chrome-mcp stop` закрывает доступ.
- Просите Claude подтверждать покупки, отправку сообщений и другие необратимые действия. В инструкциях сервера это уже прописано.
- Страницы сайтов могут содержать вредные инструкции (prompt injection). Не давайте Claude полный доступ к банкам и почте без присмотра.

## Если не работает

| Симптом | Решение |
|---|---|
| `Chrome недоступен` | Включите **Отладку по USB** и откройте Chrome один раз |
| `adb не подключился` | Включите **Отладку по Wi-Fi** (нужен Wi-Fi), повторите `chrome-mcp start`. Если не помогло, выполните `chrome-mcp setup` |
| `Туннель не смог соединиться` | Выключите и снова включите VPN или смените сеть |
| Claude пишет, что коннектор не отвечает | `chrome-mcp status`. Если Termux был закрыт системой, выполните `chrome-mcp start` и замените адрес в коннекторе |
