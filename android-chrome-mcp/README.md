# Claude в вашем Chrome на Android

Claude выполняет задачи в Chrome **в фоне**, а вы пользуетесь телефоном как обычно.
Ему доступен **только Chrome**: экран, другие приложения и уведомления он не видит.

## Установка — одна команда

1. Установите **Termux** с [F-Droid](https://f-droid.org/packages/com.termux/) или [GitHub](https://github.com/termux/termux-app/releases). Версия из Google Play не подойдёт.
2. Откройте Termux, вставьте строку и нажмите Enter:

```
pkg upgrade -y; curl -fsSL https://cdn.jsdelivr.net/gh/wddis/pol@260c78c61afc01449aba6915442745609b2596b0/android-chrome-mcp/install.sh | bash
```

3. Дальше мастер **сам откроет нужные экраны настроек** и подскажет, что нажать. Нужен Wi-Fi, около 3 минут.
4. В конце он покажет адрес и откроет claude.ai. Добавьте адрес в **Настройки → Коннекторы → Добавить свой коннектор**, поля OAuth оставьте пустыми.

Всё. Теперь пишите Claude, например:
> Открой в моём Chrome ozon.ru и найди 5 лучших беспроводных наушников до 3000 ₽.

## Каждый день

Откройте Termux и введите:
```
chrome-mcp
```
Откроется меню: запустить, остановить, показать адрес, доступ к вашим вкладкам, смена секрета, обновление.

> Если адрес изменился (так бывает после перезагрузки телефона), программа скажет об этом и откроет claude.ai, чтобы его заменить.

## Если что-то не так

| Проблема | Что сделать |
|---|---|
| Ошибка при установке (`TLS`, `404`) | Включите или выключите VPN и повторите команду |
| «Туннель не соединился» | Включите или выключите VPN либо смените сеть, затем в меню нажмите «1» |
| Claude пишет, что коннектор не отвечает | Откройте Termux и выполните `chrome-mcp` → «1» |
| Не получилось сопряжение | `chrome-mcp` → «7» (настройка заново) |

Подробности о том, как это устроено, о безопасности и постоянном адресе: [DETAILS.md](DETAILS.md).
