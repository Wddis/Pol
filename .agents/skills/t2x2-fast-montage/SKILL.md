# Быстрый монтаж T2x2

Проверь ошибки на коротких фрагментах до полной сборки. Повторно используй подтверждённые промежуточные файлы.

1. Открой `pipeline/AGENTS.md`, `STYLE_SPEC.md`, `MONTAGE.md` и `PITFALLS.md` (последние три также в `pipeline/`). Запусти `clip doctor`. Для возобновления прочитай `run.json`, свежий лог и `qa.json`, используй прежний `--job`. Помечай состояние по последнему подтверждённому этапу.
2. Найди границы в реестре или VOD. Зафиксируй EDL во времени исходника. Проверь ±10–15 секунд у каждой склейки. Сохраняй реакцию, смысл и последовательность игры. Донат с реакцией оставь целиком. Соблюдай порядок утверждённых эпизодов.
3. До сборки MP4 проверь обработанный звук вокруг окон цензуры и трекинг на сменах рекламного креатива. Подозрение ASR проверь на слух по исходному и обработанному звуку. Мат обрывай внутри слова, без бипа. Для баннера собери контактную сетку пропусков, сверь индексы кадров после seek и подгони маску по видимому контуру.
4. Правка цензуры → пересобери AAC и подставь через stream copy при совпадении таймлайна. Правка маски → пересобери только затронутые видеочанки. Сохрани прежний мастер до проверки нового. У FFmpeg должны быть тайм-аут и ограниченная длительность.
5. Проверь итоговые файлы по длительности, кадрам, разрешению, fps, громкости и true peak (≤ −1 дБTP после AAC), а также исправленные кадры и окна. Обе версии используют один монтаж и AAC. Выдай реальное качество источника. Сохрани EDL, маски, транскрипт и QA.
6. По умолчанию собирай только мастер в качестве исходника, до 1080p60. Мобильная версия нужна по отдельному запросу (`--with-preview`). Для утверждения дай ссылку на проверенный мастер, короткий отчёт и метаданные. Главы считай из финального EDL. Критичный сбой QA удерживает выдачу финала и публикацию. Публикация требует явной команды. Content ID и возрастная проверка остаются в YouTube Studio.

Пример: вращающийся баннер и восемь срабатываний ASR после рендера. Сначала прослушай восемь окон и проверь сетку переходных кадров. Правь только подтверждённые случаи и затронутые чанки. После новой сборки проверь AAC и кадры до выдачи.
