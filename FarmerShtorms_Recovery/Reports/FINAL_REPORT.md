# Farmer Shoot — Recovery Phase 1: итоговый отчёт

## 1. Исходный файл
`Original/Test.so` — 207,7 МиБ, SHA256 `a667df2a…e5a65a5b` (`Original/SHA256SUMS`). Копия доступна только для чтения (chmod 444). Оригинал в рабочем каталоге не изменялся.

> **Поправка (Phase 1.1):** повреждение — это 1999 байт, вырезанных из середины файла (сдвиг), а не обнуление. DYNAMIC, .dynsym, релокации и таблица 627 811 функций уцелели. См. `offsets_recovered.md`.

## 2. Результат анализа
- **Объединённая** библиотека Unity: движок + IL2CPP-код игры (путь сборки `/workspace/farmershoot/TempMerger/...`).
- **Повреждена:** обрезан хвост (нет таблицы секций), обнулено около 7,7 МБ в сегментах данных, включая DYNAMIC. Запустить нельзя, стандартные инструменты (nm/objdump/Il2CppDumper) не работают.

## 3. Архитектура
**arm64-v8a** (ELF64 AArch64 LE, ET_DYN, страницы 16 КБ). Достоверность 100 %.

## 4. Версия Unity
**6000.3.13f1 (Unity 6.3), changeset 3b0d9f02b51c, помечена `_patched`.** Достоверность высокая. Backend — **IL2CPP** (подтверждён строками рантайма, Mono отсутствует).

## 5. Обнаруженные компоненты
Подробно — в `Analysis/strings_report.md` и `dependencies.md`. Кратко: 502 сборки, 110 из них `Axbot.farmershoot.*`. Онлайн-шутер с режимами Deathmatch/TDM/Defuse/Duel/Ranked/Tournament/Training, магазин оружия, скины, перчатки, гранаты (в т. ч. молотов), бомба, граффити, реплеи, чат, кланы, матчмейкер (HTTP+SSE), выделенные серверы Agones, сеть ENet, DI VContainer, Firebase, Adjust, Intercom, Steam Audio, PhysX, Burst, Input System, TMPro.
**Игровых систем «фермы» в бинарнике не найдено.**

## 6. Недостающие файлы
См. `Documentation/missing_files.md`. Главное: `global-metadata.dat` + целая `.so` той же сборки (то есть APK), а лучше — `Library/ScriptAssemblies/*.dll` или репозиторий.

## 7. Реалистичная оценка
| Что | Из Test.so | С APK (metadata + целая .so) | С DLL из Library | С репозиторием |
|---|---|---|---|---|
| Структура модулей | ✅ | ✅ | ✅ | ✅ |
| Имена классов/методов | ✅ без привязки | ✅ с сигнатурами | ✅ | ✅ |
| Логика (тела методов) | ❌ (только безымянный asm) | ⚠️ псевдокод (Cpp2IL/Ghidra) | ✅ ~исходный C# | ✅ |
| Ассеты/сцены | ❌ | ✅ AssetRipper | ❌ | ✅ |
| Рабочий проект | ❌ | ⚠️ частично, вручную | ⚠️ код без ассетов | ✅ |

**Вывод: из одного Test.so игровые механики и исходный код восстановить невозможно.** Ничего не реконструировано: папки `Decompiled/` и `Reconstructed/` намеренно пусты, выдуманного кода нет.

## 8. План фазы 2
1. Найти APK/AAB/XAPK этой сборки (Unity 6000.3.13f1, arm64) или `Library/ScriptAssemblies`/репозиторий.
2. Проверить совпадение: строка `6000.3.13f1 (3b0d9f02b51c)` и Build-ID `69815f2befe135c2` в новой `.so`.
3. Если найдены DLL → ILSpy → C#-проект в `Decompiled/` (с пометкой «декомпилировано»).
4. Если найдены только APK → Il2CppDumper/Cpp2IL (metadata + .so) → dummy-DLL + `script.json` → Ghidra; AssetRipper → ассеты.
5. Сопоставить результаты с `Extracted/` и собрать проект на Unity 6000.3.x в `Reconstructed/`.
6. Без новых файлов: можно загрузить Test.so в Ghidra как raw AArch64 по карте сегментов, но это даст только безымянный код. Не рекомендую.

## ⚠️ Замечание о происхождении
Масштаб кода (110 собственных сборок, ранговый матчмейкинг, кланы, баны, Agones-кластер, античит-подобные отчёты, IAP) соответствует крупному коммерческому мобильному шутеру, а не инди-проекту про ферму со скриншота. Движок помечен как `_patched`, а имена (`Axbot`, `farmershoot`) выглядят подставленными. Фаза 2 (дамп метаданных и декомпиляция) имеет смысл и допустима только для кода, права на который принадлежат вам или вашей команде.
