# Ремонт Test.so — отчёт и доказательства

## Что было сломано
Из файла вырезаны **1999 байт** внутри `.rodata`: в секции строковых литералов встроенных метаданных IL2CPP. Всё, что лежит после разрыва, сместилось на −1999. Из-за этого таблица секций «уехала» за конец файла, а все file-offset кода и данных разошлись с vaddr.

## Как найдена точка
1. По трём независимым признакам определён сдвиг на ровно 1999 байт:
   - DYNAMIC находится по 0xc89fc28 − 1999;
   - сигнатура `.eh_frame_hdr` (`01 1b 03 3b`) найдена по 0x3e0fa10 − 1999;
   - на столько же не хватает байт таблице секций.
2. Сдвиг локализован по ссылкам из кода (ADRP+ADD) и из 1,14 млн релокаций: ссылки на строки до 0x1BD4D18 совпадают без сдвига, после 0x3A7… — только со сдвигом.
3. В промежутке найден блок 22 МБ (vaddr 0x1C04200), на который ссылается **один** указатель. Это встроенные метаданные IL2CPP с заголовком 0x100 байт, где поля перемешаны, а magic/version заменены (антидамп). Смещения из заголовка показали:
   - секция с заголовочным смещением 0x011fbbcc читается **без** сдвига;
   - секция 0x012d9c44 и все следующие — **со** сдвигом.
   Значит, разрыв лежит внутри секции [0x011fbbcc, 0x012d9c44): это данные строковых литералов C#.

## Ремонт
`Repaired/Test_repaired.so` = `Original[:0x2EDD675] + 1999 × 0x00 + Original[0x2EDD675:]`. Нули вставлены в конец секции литералов.
Оригинал не изменялся. SHA256: `Repaired/SHA256SUMS`.

## Что это дало
- 27 секций, в том числе `.note.unity` (`Unity Technologies 6000.3.13f1_3b0d9f02b51c` — версия теперь подтверждена официальной нотой) и `.gnu_debuglink` → **`libunity.sym.so`**: файл символов, который Unity генерирует при сборке.
- DT_NEEDED: libandroid, libz, libEGL, libmediandk, libm, libdl, libc. SONAME: `libunity.so`.
- Файл открывается в Ghidra/IDA как обычный ELF ARM64.

## Ограничения (честно)
- Сами 1999 байт утеряны: заменены нулями. Это 1999 байт **текста строковых литералов C#**. Код, таблицы и указатели не пострадали.
- Точное место разрыва внутри секции литералов (~900 КБ) не определено: нули вставлены в её конец. Если реальный разрыв был раньше, литералы между ним и концом секции остаются сдвинутыми на 1999 байт. Как только будет найдена таблица индексов литералов, место можно уточнить.
- Запустить игру с этим файлом нельзя: нет APK и ассетов.
