# Возможности восстановления

## 1. Можно ли «побайтово вернуть рабочий вид» этому файлу?

**Частично и только с оговорками.** Что выяснено:

- В файл вставлено 2113 лишних байт (0x841), вероятно в нескольких местах внутри `.rodata`.
- Всё, что после них (`.eh_frame`, весь код `.text`, `.data`, `.dynamic`, таблица секций), **цело, но сдвинуто**.
- Байты не «испорчены»: структуры `.dynamic`, `.rela`, код читаются корректно со сдвигом.

Чтобы получить точный оригинал, нужно найти **каждую** точку вставки и удалить ровно вставленные байты.
Без эталона это однозначно сделать нельзя: в `.rodata` лежат плотные таблицы, и статистические зонды
дают только диапазоны (`Extracted/alignment_shift_map.txt`).

Варианты:
1. **Лучший путь:** найти любую другую копию этого же файла (из APK/AAB, бэкапа, CI-артефактов, Google Play Console →
   App bundle explorer, устройства: `/data/app/<pkg>/lib/arm64/libunity.so`). Сверить SHA256 / Build ID `69815f2befe135c2`.
2. Если есть `libunity.sym.so` (упомянут в `.gnu_debuglink`) — по нему можно уточнить раскладку и получить имена функций.
3. Без эталона: удалить 0x841 байт в точке, выбранной эвристически. Получится файл, у которого заголовки,
   `.dynamic`, код и данные станут согласованы, но небольшой участок `.rodata` останется смещённым на 1–3 байта.
   Такая библиотека **годится для анализа в Ghidra/IDA**, но запускать её в игре нельзя — поведение непредсказуемо.
   Этот шаг ещё не выполнен: он меняет данные, и решение за вами.

Даже идеально починенный `libunity.so` **сам по себе игру не запустит**: нужны ещё `global-metadata.dat`,
ресурсы (`data.unity3d`/`*.assets`/`*.bundle`), Java-часть (`classes.dex`), остальные `.so` плагинов.

## 2. Можно ли восстановить C#-код игры?

**Из этого файла — нет.** Сгенерированный IL2CPP код лежит в `.text` в виде машинных инструкций ARM64,
но без `global-metadata.dat` нет:
- имён классов, методов, полей и их привязки к адресам;
- сигнатур методов, типов, строковых литералов C#.

С `global-metadata.dat` того же билда: Il2CppDumper / Cpp2IL / Il2CppInspector дают имена всех типов и методов,
адреса, `dump.cs` (сигнатуры без тел), DummyDll, скрипты для Ghidra/IDA. Тела методов — только псевдокод
декомпилятора (ARM64 → C) или приблизительный IL от Cpp2IL. **Оригинальный C# побайтово не восстанавливается
никаким инструментом.** Исходники — только из бэкапа/git.

## 3. Инструменты

| Инструмент | В контейнере | Подходит к Test.so? | Комментарий |
|---|---|---|---|
| readelf | есть | частично | после ремонта сдвига — полностью; сейчас падает на `.dynamic` |
| objdump / llvm-objdump | есть | частично | дизассемблирование по ручным смещениям |
| nm | есть | нет | нет `.symtab`; `nm -D` упирается в битый `.dynamic` |
| strings | есть | **да** | основной источник информации на этом этапе |
| Ghidra | нет | **да** (после ремонта) | лучший бесплатный декомпилятор ARM64; Java в контейнере есть |
| IDA Pro | нет | **да** | коммерческий; лучшая работа с большими бинарниками |
| radare2 | нет | да | можно установить; файл 217 МБ — анализ медленный |
| Il2CppDumper | нет | **нет без global-metadata.dat** | ищет `g_CodeRegistration`/`g_MetadataRegistration`, нужен metadata |
| Cpp2IL | нет | **нет без metadata** | то же |
| Il2CppInspector | нет | **нет без metadata**, и не поддерживает metadata Unity 6 | устарел |

Примечание: для Unity 6000.x metadata обычно версии 31+; нужны свежие форки Il2CppDumper/Cpp2IL.
Если IL2CPP-код действительно слит в libunity.so, инструментам нужно указать этот файл вместо libil2cpp.so.

## 4. Реалистичная оценка

| Что | Вероятность восстановления только из Test.so |
|---|---|
| Версия Unity, ABI, зависимости, список плагинов | ✅ сделано |
| Список сборок и пространств имён игры | ✅ сделано (имена, без содержимого) |
| Рабочий `libunity.so` побайтово | ⚠️ ~30 %, без эталона — нет гарантии |
| Файл для анализа в Ghidra (структурно согласованный) | ✅ ~90 % |
| Имена C#-классов/методов | ❌ нужен global-metadata.dat |
| Исходный C#-код | ❌ невозможно (только бэкап/VCS) |
| Сцены, модели, текстуры, звуки, префабы | ❌ их нет в .so |
| Рабочая сборка игры | ❌ нужен весь APK/AAB |
