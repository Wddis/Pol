# Возможности восстановления

## Инструменты
| Инструмент | Есть здесь | Подходит? |
|---|---|---|
| readelf | да (2.42) | Частично: заголовок и сегменты читаются, секции и dynamic — нет |
| objdump / nm | да | **Нет**: «file too short / format not recognized» без заголовков секций |
| strings | да | **Да**: основной источник данных сейчас |
| radare2 / Ghidra / IDA | нет | Да, если загрузить файл как raw AArch64 по карте сегментов. Это даст дизассемблирование и псевдокод **без имён** (~107 МБ кода, сотни тысяч функций) |
| Il2CppDumper / Il2CppInspector / Cpp2IL | — | **Нет**: все три требуют `global-metadata.dat`. Кроме того, регистрационные структуры частично лежат в обнулённых областях |

## Что реально извлечь из этого файла
- ✅ Версия Unity, ABI, scripting backend, подсистемы, SDK.
- ✅ Список сборок, пространств имён и около 175 тыс. имён типов, методов и полей, без привязки к коду и без сигнатур.
- ✅ Структура проекта (модули, режимы, ScriptableObject-определения оружия и эффектов).
- ⚠️ Машинный код игровой логики есть, но без метаданных он безымянный. Ручной реверс отдельных функций возможен, но это месяцы работы, и на выходе будет псевдокод, а не исходники.
- ❌ C#-исходники, сцены, префабы, модели, текстуры, звуки, настройки — **в .so их нет и никогда не было**.
- ❌ Запустить файл нельзя: DYNAMIC и часть данных обнулены.

## Оценка
Восстановить из одного этого файла **исходный проект невозможно**. Если найти `global-metadata.dat` **той же сборки** и неповреждённую копию этой `.so`, то Il2CppDumper/Cpp2IL дадут dummy-DLL с именами и сигнатурами всех классов и методов (без тел), а Cpp2IL — частичный IL/псевдо-C#. Ассеты извлекаются из APK/OBB (AssetRipper).
