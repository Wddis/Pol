# Контекст для Claude: Telegram-аккаунт пользователя и розыгрыши

Пользователь — владелец Telegram-аккаунта **Sahalinov (@dpoltin)**. Claude работает с аккаунтом
через пользовательский API (MTProto, GramJS) из папки `tg/` и участвует в розыгрышах по правилам ниже.
Общаться с пользователем по-русски, кратко.

## Подключение (каждая новая облачная сессия)
1. `cd tg && npm install` (Playwright/Chromium уже предустановлены в среде: `NODE_PATH=$(npm root -g)`).
2. Переменные: `TG_API_ID`, `TG_API_HASH` (Desktop-приложение с my.telegram.org). Если их нет в окружении — спросить у пользователя.
   Никогда не коммитить ключи и `session.txt`.
3. Прямой TCP к Telegram из облака закрыт — `tg.js` ходит через WebSocket `*.web.telegram.org`
   (патч `PromisedWebSockets` + `global-agent` через HTTPS_PROXY). Хосты `*.web.telegram.org`, `my.telegram.org` должны быть разрешены в сети среды.
4. Вход: `NODE_EXTRA_CA_CERTS=/root/.ccr/ca-bundle.crt node tg.js qr` → пишет `qr.png` (обновляется каждые ~30 с).
   Отправить пользователю картинку сразу после обновления; он сканирует со второго экрана
   (Telegram → Настройки → Устройства → Подключить устройство). Код по SMS/в приложение из облака не доходит (антифрод).
5. Дальше: `node tg.js run <script.js>` — скрипт экспортирует `async (client, Api) => {}`.

## Инструменты в tg/
- `tg.js` — клиент, вход (qr / sendcode / signin), запуск скриптов.
- `joinlist.js` — подписка на каналы из `CHANNELS=a,b,+invite` с паузами 15–20 с; новые id пишет в `state/joined.json`.
- `archive.js` — перенос всех новых каналов в архив.
- `wv.js` + `pw3.js` — открыть мини-апп бота розыгрыша (`BOT= APP= START=`) и прочитать статус в headless Chromium.
- `startbot.js` — `/start <param>` боту (GiveShareBot, bestrandom, TicketsBot и т.п.) и чтение ответа.
- `webk.js` — открыть пост в Telegram Web K с текущей сессией (для постов «нового формата», которые GramJS видит как MessageMediaUnsupported); `CLICK=<текст кнопки>` достаёт startapp.
- `aggr4.js` — выгрузка постов каналов-сборников; `results3.js` — проверка исходных постов на итоги; `wins.js` — поиск сообщений о победе в личке.

## Правила участия в розыгрышах
Источники: @raffleblog, @GoldAppleTeens, а также сборники @draweverything, @uchastvovat, @PrizeTech, @konkyrstelegram, @rozygrysh_telegramm.
- Итоги не позже чем через ~30 дней.
- Приз: техника/гаджеты (iPhone, AirPods, PS5, ПК…), деньги на карту, сертификаты **только WB/Ozon**, доставка по РФ (СДЭК и т.п.) или в посте не указана (пометка 🔸).
- НЕ участвовать: бьюти, витамины/БАДы, билеты, еда, дешёвые игрушки, сертификаты других магазинов, футбольная/хоккейная форма и мерч, «стикеры на акцию»/машины, крипто-кошельки.
- НЕ участвовать, если условие требует: Instagram/TikTok/VK/MAX/YouTube, комментарии, сторис, пересылку поста друзьям, обязательное приглашение друзей, оплату, ввод ФИО, промокод на игровом сервере, «актив».
- НЕ участвовать в местных: только для жителей города/области, самовывоз из магазина, Беларусь.
- Капчу («Робот или человек?», примеры, DDoS-Guard) Claude НЕ проходит — просит пользователя и помечает ✋.
- Подписки — с паузами (лимит Telegram: 500 каналов); всё новое сразу в архив. Реакции ставить, если требуется.
- Если итоги прошли без победы или не объявлены через 1–3 дня после даты — отписаться от каналов этого конкурса (кроме тех, на которые пользователь был подписан сам).

## Отчёт
В «Избранном» (Saved Messages), последними сообщениями, первое закреплено. Старый удалять.
Формат: шапка со сводкой (всего / ✅ впереди / ✋ нужно действие / выигрыши), блок ✋, затем по неделям
с иконками 📱🎮🎧💻💰🎁, пометки 🔸 (доставка не указана) и 🆕. Лимит сообщения 4096 символов.
